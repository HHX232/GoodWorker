# 0029. D04–D06: пороги «блестящего» и «отличного» хода

**Контекст**
План: блестящий — если до хода сторона «не выигрывала подавляюще» (win% < 90); у отличного есть ветка «проигранная позиция < 30 % → равная»; 13.Лxd7 в «Оперной партии» ожидался блестящим.

**Решение**
Код показал: win% < 90 для блестящего считается по лучшей альтернативе сыгранному ходу, а не по позиции до хода (D04). Ветка «< 30 → ≥ 45» у отличного убрана; спасение реализуется первой веткой — единственный ход после ошибки соперника (D05). Порог жертвы «≥ 2 пешки» остаётся: позиционная 13.Лxd7 (материал после размена равен) не блестящая, 16.Фb8+ — блестящий (D06).

**Почему**
Условие по позиции до хода отвергли: в матующей комбинации топ-линия уже ~100 %, и матующая жертва никогда не стала бы блестящей. Ветку «< 30 → ≥ 45» отвергли как недостижимую: потерять ≤ 2 % и при этом поднять win% на 15+ пунктов можно только из-за шума движка. Ослабить порог жертвы ради 13.Лxd7 отвергли — тогда блестящими стали бы обычные размены.

**Последствия**
Классификация расходится с chess.com на позиционных жертвах — известную «блестящую» партию пользователь может увидеть без алмаза. Отличный ход теперь зависит от того, ошибся ли соперник предыдущим ходом, — модель смотрит на два хода назад.
