# 0018. Папку для конспекта выбирает DeepSeek на каждого участника; у репетитора только внутри «Конспекты уроков»

**Контекст**
У каждого участника своё дерево папок. Папки библиотеки репетитора могут быть открыты ученикам через гранты. Бриф просит, чтобы папка определялась индивидуально, по предмету и преподавателю.

**Решение**
Для каждого участника отдельный вызов `chooseFolder` получает предмет, тему, имя преподавателя, имя ученика (для репетитора) и дерево папок этого человека. Ученику разрешена любая его папка или новый путь не глубже `MAX_FOLDER_DEPTH`. Репетитору выбор ограничен корнем «Конспекты уроков»; вне его модель ничего не выбирает. Без ИИ путь — «Конспекты уроков/<Предмет>».

**Почему**
Отвергли единую папку для всех («Конспекты уроков»): бриф прямо говорит, что у каждого она может быть своей, а ученик уже раскладывает файлы по предметам. Отвергли свободный выбор для репетитора: папка, которую ИИ выберет в его библиотеке, может оказаться расшаренной ученику, и конспект с чужими репликами и разбором попал бы к тем, кому не предназначен. Утечка из-за ошибки модели необратима, поэтому ограничение стоит в коде, а не в промпте.

Отдельный вызов на человека, а не один общий, потому что деревья папок разные.

**Последствия**
Один урок с N участниками — N+ вызовов ИИ на этапе финала. Репетитор не получит конспект в «своей» тематической папке, пока она не лежит под «Конспекты уроков»: ИИ только создаёт подпапки внутри корня. Модель может создать нестабильные ветки («Математика» и «Алгебра» рядом), поэтому в промпт нужно отдавать существующие папки и просить переиспользовать их. Если репетитор переименует или расшарит «Конспекты уроков» целиком, защита перестаёт работать — это условие нужно помнить при изменении грантов.
