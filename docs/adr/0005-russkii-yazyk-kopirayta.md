# 0005. Русский язык как единственный язык копирайта

**Контекст**
Продукт потенциально многоязычный (EN/ZH/HI), но лендинг PDF→Test делается для выбора визуального направления, и язык копирайта в брифе явно не задан.

**Решение**
Весь копирайт — на русском; каноничные строки лежат в копирайт-деке (`interfaces.md`), едины для всех трёх вариантов. Мультиязычность (i18n, EN/ZH/HI) — вне рамок этого этапа.

**Почему**
На этапе выбора визуального языка важен характер верстки, а не охват локалей; один язык даёт честное сравнение вариантов без умножения текста. Рассмотрели «сразу i18n / несколько языков»: тянет за собой систему переводов, длину строк под разные языки и тройную вычитку — всё это ради черновиков, из которых выживет один. Отвергли как преждевременное усложнение: пользователь выбрал русский, мультиязычность делается потом, поверх победителя.

**Последствия**
Живём с монолингвальным дек-контрактом: добавление языка позже потребует ретроспективно ввести слой переводов и, возможно, переверстать блоки под другую длину строк. Верстка вариантов может неявно опираться на длину русских фраз — при локализации это всплывёт как правки макета.
