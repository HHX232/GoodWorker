# 0021. Stockfish считает в браузере (lite single-thread WASM), а не на сервере

**Контекст**
Нужен сильный движок для игры, бесплатной безлимитной оценки каждого хода и разбора партии, в том числе для гостей.

**Решение**
Движок — Stockfish из npm `stockfish` (GPL-3), сборка lite single-thread WASM в Web Worker. Файл воркера (~7 МБ) копируется скриптом в `public/stockfish/`, пакет лежит в `devDependencies`. На странице игры есть ссылка «Движок Stockfish, GPL-3, исходники».

**Почему**
Серверный движок отвергли: каждая оценка хода и прогон партии стоили бы CPU сервера, а «бесплатно и без лимита для гостей» превратилось бы в открытую дверь для нагрузки. Многопоточную сборку отвергли: ей нужны заголовки COOP/COEP, которые ломают встраиваемые ресурсы сайта (видео, картинки с S3, iframe). Самописный бот уже был и слаб. Импорт движка в бандл отвергли из-за размера и GPL: отдельный файл в `public/` держит границу лицензии.

**Последствия**
Сила и скорость анализа зависят от устройства: на слабом телефоне глубина 14 и 0,6 с/позицию в разборе — это потолок. Без WASM движка нет — нужна деградация до игры «вдвоём на одной доске». Сервер не может доверять оценкам клиента: всё, что считает движок, непроверяемо (см. 0027). В репо лежит бинарник ~7 МБ, обновление версии — ручной перезапуск скрипта копирования.
