# 0018. Баланс заменяет VIP-гейт на 5 из 7 AI-эндпоинтов, а не накладывается поверх (G01)

## Контекст

5 из 7 AI-эндпоинтов (`whiteboard/formula-ai`, `formula-photo`, `pdf-to-test/photos`,
`teacher/lesson-plan`, `lesson-plan/revise`) были закрыты целиком для не-VIP (403).
Ещё 2 (`pdf-to-test`, `tests/import-pdf`) VIP лишь расширял — формат/лимит страниц.

## Решение

Для этих 5 эндпоинтов проверка `isVip` убирается; доступ решает исключительно баланс
(preflight + списание). VIP на них больше не влияет вовсе — ни в плюс, ни в минус.

## Почему

Рассмотрели «баланс поверх VIP» (VIP по-прежнему открывает доступ бесплатно и безлимитно,
баланс — только для не-VIP) — отвергли по прямому требованию заказчика (G01): цель брифа
— платить за реальный расход, а не давать VIP-пользователям расходовать AI бесконечно без
покрытия себестоимости. Сохранение VIP-гейта поверх баланса оставило бы исходную проблему
нерешённой именно для той группы пользователей, ради которой AI дороже всего обходится
платформе.

## Последствия

VIP-пользователь без баланса теперь получает 402 на этих 5 эндпоинтах — раньше VIP
гарантировал доступ безусловно, теперь ничего не гарантирует там (только 2 оставшихся
эндпоинта VIP по-прежнему расширяет — G02, отдельно не тронуто). Это потребовало
отдельного захода на клиентские `isVip`-гейты, которые блокировали запрос ещё до бэкенда
и делали новую модель недостижимой на фронтенде, пока их не сняли (см. ADR 0020 / D02).
Откат к «VIP = безлимит» на этих 5 эндпоинтах — не просто отмена одной серверной
проверки, а пересмотр ценностного предложения VIP, о котором придётся заново сообщать
пользователям.
