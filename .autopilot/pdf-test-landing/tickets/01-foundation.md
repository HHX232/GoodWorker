## Что должно заработать

Появляется каркас прототипов: папка `ForNewDesign/prototypes/`, общий
`shared/switcher.js` (переключатель V1/V2/V3 + сохранение доли скролла между
страницами) и `shared/reveal-core.js` (IntersectionObserver, ставит `.is-in`,
уважает reduced-motion). Плюс `index.html` — входная страница-сравнение: три
крупные ссылки-карточки на варианты с одной строкой про каждый мир и общий
переключатель. Открывается двойным кликом, работает офлайн.

## Из брифа, дословно

> «сделать несколько вариантов этого сайта»
> «с возможностью переключения этих вариантов между собой»
> «Варианты должны быть принципиально разные … чтобы можно было потом выбрать лучшую из версий»

## Разделы спецификации

Решения (формат, расположение, переключатель, reveal-словари); Границы и швы;
`interfaces.md` — контракт переключателя и reveal-ядра (соблюдать дословно).

## Критерии приёмки

- [ ] `shared/switcher.js` реализует контракт из `interfaces.md`: `aria-current` активному, запись `sessionStorage['pdfland:scrollRatio']` при клике, восстановление доли скролла на загрузке (мгновенно при reduced-motion).
- [ ] `shared/reveal-core.js` реализует контракт: `.is-in` на `[data-reveal]` при въезде (порог ~0.15), при reduced-motion — сразу всем без анимации.
- [ ] `index.html` — 3 ссылки на варианты (`variant-a-swiss.html`, `variant-b-terminal.html`, `variant-c-cinematic.html`), у каждой строка про мир (V1 Swiss / V2 Terminal / V3 Cinematic), общий `<nav data-switcher>`.
- [ ] Всё открывается по `file://` без ошибок в консоли; ссылки резолвятся (файлы вариантов появятся в волне 2 — ссылки статические, это ок).
- [ ] index сам по себе Ч/Б, минималистичный, с воздухом (не конкурирует с вариантами по стилю — нейтральная витрина).
- [ ] `index.html` дописывает контракт-блок в `interfaces.md` (что построено).

## Заметки исполнителю

- Никаких внешних JS-библиотек. Vanilla JS, `defer`.
- Переключатель и reveal-ядро подключаются во ВСЕ страницы одинаково — не меняй их API, варианты на него завязаны.
- Синк скролла: доля = `scrollY / (scrollHeight - innerHeight)`; на целевой странице применяй после полной загрузки/layout.
