## Что должно заработать

Полноценный одностраничный лендинг PDF→Тест в мире **Cinematic / Gallery**: тёплый
светлый «музейный» фон, крупный высококонтрастный serif (Didone), большие планы,
максимум негативного пространства, драматичные Ч/Б плоскости, «киношная» медленная
моторика. Hero — крупный документ, запиненный на скролле, медленно превращается в
тест; указатели появляются как киношные подписи/тонкие выносные. Дальше — 8 секций,
каждая иначе соседней, reveal-приёмы мира (параллакс, scale-rise, sticky-морф).
Переключатель и reveal-ядро — из тикета 01.

## Мир V3 (из interfaces.md)

- Дисплей `Bodoni Moda` (Didone, 400/700/900 + italic), текст `Archivo`/`Manrope`. Fallback `Georgia, serif`.
- Палитра `--bg:#f3f0ea; --ink:#0c0a08; --ink-2:#6a655c; --line:#ddd7cc`. Без цвета; тон несёт контраст и крупные Ч/Б плоскости. (Отличаться от тёмного V2 и холодного V1.)
- Ритм: большие планы, максимум воздуха, драматичные Ч/Б блоки, медленная моторика.
- Reveal: параллакс слоёв · scale-rise (0.92→1 + fade) · sticky-пиннинг hero с морфингом.
- Hero: запиненный документ медленно морфит в тест; callouts — киношные подписи/тонкие выносные.

## Критерии приёмки

- [ ] Все 8 секций из дека собраны, тексты — дословно из копирайт-дека, русский.
- [ ] Hero: анимация процесса PDF→тест по scroll-trigger (sticky-пиннинг) + 3–5 указателей; на месте будущего видео (`data-placeholder`), без сломанных медиа.
- [ ] Reveal работает на секциях через `[data-reveal]` + `.is-in`; показаны ≥2 разных приёма мира; при `prefers-reduced-motion` движение выключено, контент виден.
- [ ] Соседние секции визуально различны (сетка/масштаб/плотность/приём) — не монотонно.
- [ ] Ч/Б, без цветных блоков; максимум воздуха; ведёт визуал; текста мало.
- [ ] Крупные планы Ч/Б собраны из вёрстки/вектора/CSS (без внешних стоковых фото — самодостаточно, офлайн).
- [ ] Primary-CTA «Загрузить PDF» видна на первом экране (`href="#"`, placeholder URL).
- [ ] `<nav data-switcher>` по контракту; подключены `shared/switcher.js` и `shared/reveal-core.js`.
- [ ] Адаптив 360 и 1440px: нет горизонтального скролла body; sticky/параллакс деградируют на мобильном.
- [ ] Serif читаем: измеримая шкала и вес; мера текста 65–75ch; tracking крупного до -0.04em.
- [ ] Иконки — рисованные SVG, не эмодзи. Нет запрещённого craft-floor.
- [ ] Дописать контракт-блок в `interfaces.md`.

## Заметки

Мир должен читаться как галерея/кино: интерфейс отступает, ведёт артефакт. Один сильный
моушен-момент — запиненный hero-морфинг. Планка — craft-floor.
