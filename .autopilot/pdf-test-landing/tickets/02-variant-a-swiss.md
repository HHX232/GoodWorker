## Что должно заработать

Полноценный одностраничный лендинг PDF→Тест в мире **Swiss / Kinetic Type**:
холодный белый, строгая типографическая сетка, огромный гротеск, волосяные линии,
максимум воздуха. Hero показывает процесс «PDF → тест» горизонтальным filmstrip'ом,
скрабящимся по скроллу, с пронумерованными указателями на выносных линиях. Дальше —
8 секций контента, каждая иначе соседней, с reveal-приёмами (mask-развёртка строк,
счётчики, отрисовка линий). Общий переключатель и reveal-ядро — из тикета 01.

## Из брифа, дословно

> «Создай одностраничный лендинг для рекламы pdf to test»
> «Сайт должен быть в приоритете черно-белым, без большого количества цветастых блоков»
> «Главная hero-секция должна иметь скролл-триггер-анимацию, где … процесс перевода pdf to test … всплывающие элементы пояснения-указатели»
> «Каждая следующая секция должна отличаться от предыдущей»

## Разделы спецификации

§Контент (8 секций + элементы внутри); §Предложенные reveal-приёмы; §Три мира → V1;
`interfaces.md` — мир V1, копирайт-дек (дословно), крафт-правила, контракты переключателя и reveal.

## Мир V1 (из interfaces.md)

- Шрифт `Archivo` (+ `Archivo Expanded` для дисплея), fallback `"Helvetica Neue", Arial`.
- Палитра `--bg:#ffffff; --ink:#0a0a0a; --ink-2:#6b6b6b; --line:#e5e5e5`. Только Ч/Б + hairlines. Акцент — чёрные плашки/подчёркивания.
- Сетка строгая 12-кол, видимые волосяные линии, широкие поля.
- Reveal: mask-развёртка (clip-path, построчно) · счётчики 0→N · отрисовка hairline.
- Hero: filmstrip PDF→карточки, скраб по скроллу, callouts на пронумерованных выносных линиях.

## Критерии приёмки

- [ ] Все 8 секций из дека собраны, тексты — дословно из копирайт-дека, русский.
- [ ] Hero: анимация процесса PDF→тест по scroll-trigger + 3–5 указателей; на месте будущего видео (`data-placeholder`), без сломанных медиа.
- [ ] Reveal работает на секциях через `[data-reveal]` + `.is-in`; показаны ≥2 разных приёма мира; при `prefers-reduced-motion` движение выключено, контент виден.
- [ ] Соседние секции визуально различны (сетка/масштаб/плотность/приём) — не монотонно.
- [ ] Ч/Б, без цветных блоков; много воздуха; ведёт визуал; текста мало.
- [ ] Primary-CTA «Загрузить PDF» видна на первом экране (`href="#"`, placeholder URL).
- [ ] `<nav data-switcher>` по контракту; подключены `shared/switcher.js` и `shared/reveal-core.js`.
- [ ] Адаптив 360 и 1440px: нет горизонтального скролла body; тяжёлые эффекты деградируют на мобильном.
- [ ] Шрифты с fallback-стеком (не рушится офлайн). Иконки — рисованные SVG, не эмодзи.
- [ ] Нет запрещённого craft-floor (градиентный текст, стекло-декор, eyebrow, бессмысленные номера секций и т.д.).
- [ ] Дописать контракт-блок в `interfaces.md`.

## Заметки

что это, зачем и что нажать. Один сильный моушен-момент — hero; не рассыпать эффекты.
