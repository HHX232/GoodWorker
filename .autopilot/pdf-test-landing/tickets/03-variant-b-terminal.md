## Что должно заработать

Полноценный одностраничный лендинг PDF→Тест в мире **Terminal / Blueprint**:
тёмный фон, моноширинный шрифт для данных/логов, точечная сетка, угловые засечки,
тонкая скан-линия. Hero — «консоль обработки»: документ сканируется построчно, живой
лог печатает шаги, выходная панель собирает карточки теста; указатели — схематичные
аннотации с выносными линиями. Дальше — 8 секций, каждая иначе соседней, reveal-приёмы
мира (decode/typewriter, line-draw, scan-wipe). Переключатель и reveal-ядро — из тикета 01.

## Из брифа, дословно

> «Создай одностраничный лендинг для рекламы pdf to test»
> «Сайт должен быть в приоритете черно-белым, без большого количества цветастых блоков»
> «Главная hero-секция должна иметь скролл-триггер-анимацию, где … процесс перевода pdf to test … всплывающие элементы пояснения-указатели»
> «Каждая следующая секция должна отличаться от предыдущей»

## Разделы спецификации

`interfaces.md` — мир V2, копирайт-дек (дословно), крафт-правила, контракты переключателя и reveal.

## Мир V2 (из interfaces.md)

- Шрифт `JetBrains Mono` (400/500/700) везде — mono для реальных данных/логов. Fallback `ui-monospace, monospace`.
- Палитра `--bg:#0d0d0f; --ink:#e6e6e3; --ink-2:#7a7a75; --line:#2a2a2e`. Микро-акцент `#d8ff3e` ТОЛЬКО 1–2px (курсор/скан/подчёркивание активного тега). Не заливки.
- Мотивы: точечная сетка фоном, угловые засечки, тонкая скан-линия-оверлей.
- Reveal: decode/typewriter · line-draw (stroke-dashoffset) · scan-wipe между секциями.
- Hero: консоль-скан документа + живой лог `→ читаю страницы… → парсинг… → 12 вопросов` + сборка карточек; callouts — схематичные аннотации с «координатами».

## Критерии приёмки

- [ ] Все 8 секций из дека собраны, тексты — дословно из копирайт-дека, русский.
- [ ] Hero: анимация процесса PDF→тест по scroll-trigger + 3–5 указателей; на месте будущего видео (`data-placeholder`), без сломанных медиа.
- [ ] Reveal работает на секциях через `[data-reveal]` + `.is-in`; показаны ≥2 разных приёма мира; при `prefers-reduced-motion` движение выключено, контент виден.
- [ ] Соседние секции визуально различны (сетка/масштаб/плотность/приём) — не монотонно.
- [ ] Ч/Б-приоритет: акцент только точечный (1–2px), без цветных блоков; много воздуха; ведёт визуал; текста мало.
- [ ] Mono оправдан данными/логами/тегами, а не декор («технично ради технично» — нельзя).
- [ ] Primary-CTA «Загрузить PDF» видна на первом экране (`href="#"`, placeholder URL).
- [ ] `<nav data-switcher>` по контракту; подключены `shared/switcher.js` и `shared/reveal-core.js`.
- [ ] Адаптив 360 и 1440px: нет горизонтального скролла body; тяжёлые эффекты деградируют на мобильном.
- [ ] Контраст на тёмном фоне ≥4.5:1 для текста; вторичный текст тонирован, не грязно-серый.
- [ ] Иконки — рисованные SVG, не эмодзи. Нет запрещённого craft-floor.
- [ ] Дописать контракт-блок в `interfaces.md`.
