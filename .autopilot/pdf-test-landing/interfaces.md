# interfaces.md — общие контракты сборки

Единый источник правды для всех исполнителей. Читается **до** написания кода.
Три варианта верстаются независимо, но делят: (1) контракт переключателя,
(2) reveal-ядро, (3) копирайт-дек. Всё визуальное — на совести мира.

---

## Правила проекта (исполнитель не может их вывести сам)

- **Стек:** статические HTML/CSS/JS. Без сборки, без npm, без фреймворков.
  «Запуск» = открыть файл в браузере (`file://`). Без бэкенда.
- **Единственная внешняя зависимость:** шрифты Google Fonts через `<link>` в `<head>`.
  Всегда с web-safe fallback-стеком (работает офлайн). Ничего больше не подключать.
  Нет CDN-скриптов, нет сторонних JS-библиотек. Всю анимацию писать руками (CSS + vanilla JS).
- **Куда писать:** только внутрь `ForNewDesign/prototypes/`. Приложение Next.js
  (`app/`, `src/`) не трогать. Инкумбент `app/info-pdf-to-test/` — только как референс мира V2.
- **Недостающая зависимость → верни `BLOCKED`**, не устанавливай ничего.
- **Верификация (смоук):** страница открывается без ошибок в консоли; ссылки
  переключателя резолвятся; при `prefers-reduced-motion: reduce` движение выключено,
  контент виден; адаптив 360px и 1440px не ломается (нет горизонтального скролла body).
  Юнит-тестов нет — прототип статичный.
- **Язык копирайта:** русский. Только строки из копирайт-дека ниже — дословно.

### Контракт переключателя (СТРОГО одинаковый во всех 4 файлах)

Разметка (fixed, поверх контента, ненавязчивая — угол экрана):
```html
<nav data-switcher aria-label="Версии лендинга">
  <a data-variant="a" href="variant-a-swiss.html">V1</a>
  <a data-variant="b" href="variant-b-terminal.html">V2</a>
  <a data-variant="c" href="variant-c-cinematic.html">V3</a>
</nav>
```
Поведение `switcher.js`: по имени текущего файла добавляет `aria-current="page"`
активной ссылке; при клике пишет `sessionStorage['pdfland:scrollRatio'] =` (scrollY /
(scrollHeight - innerHeight)); на загрузке любой страницы, если ключ есть —
восстанавливает скролл по доле (после layout, с учётом reduced-motion — мгновенно).
Стиль `<nav data-switcher>` каждый мир задаёт под себя, но позиция и размер —
компактные, не перекрывают hero-CTA.

### Контракт reveal-ядра

`reveal-core.js`: находит `[data-reveal]`, вешает IntersectionObserver (порог ~0.15),
при въезде добавляет `.is-in` (один раз). Если `matchMedia('(prefers-reduced-motion:
reduce)')` — сразу ставит `.is-in` всем и не анимирует. Что делает `.is-in` визуально —
определяет CSS каждого мира. Дополнительные data-атрибуты (`data-reveal="mask"`,
`data-reveal-delay`) мир может использовать по-своему.

- Заголовок: `Из PDF — в готовый тест. Автоматически.`

## Три мира (R12 — принципиально разные)

Общее для всех: приоритет Ч/Б; много воздуха; акцент на визуале; каждая секция иначе,
чем соседняя; один сильный авторский моушен-момент (hero-процесс); reveal на секциях.

### V1 — Swiss / Kinetic Type (файл `variant-a-swiss.html`)
- **Шрифт:** `Archivo` (400/600/800), дисплей — `Archivo Expanded` если доступен. Fallback `"Helvetica Neue", Arial, sans-serif`.
- **Палитра:** холодная белая. `--bg:#ffffff; --ink:#0a0a0a; --ink-2:#6b6b6b; --line:#e5e5e5`. Без цвета — только чёрный/белый и волосяные линии. Акцент = сплошные чёрные плашки/подчёркивания.
- **Сетка:** строгая 12-колоночная, видимые hairline-линии, широкие поля, крупная типографика.
- **Reveal:** mask-развёртка строк (clip-path, снизу вверх, построчно) · счётчики (0→N) · отрисовка hairline-линий.
- **Hero-процесс:** горизонтальный «filmstrip» — миниатюра PDF слева → стрелки → карточки вопросов справа; прогресс по скроллу скрабит трансформацию (страница сканируется, карточки собираются); callouts — пронумерованные подписи на выносных hairline-линиях.

### V2 — Terminal / Blueprint (файл `variant-b-terminal.html`)
- **Шрифт:** `JetBrains Mono` (400/500/700) везде — легитимный mono для данных/логов. Fallback `ui-monospace, monospace`.
- **Палитра:** тёмная. `--bg:#0d0d0f; --ink:#e6e6e3; --ink-2:#7a7a75; --line:#2a2a2e`. Микро-акцент — один фосфорный сигнал `#d8ff3e` ТОЛЬКО на 1–2px: живой курсор, скан-линия, подчёркивание активного тега. Не заливки (R02).
- **Мотивы:** точечная сетка фоном, угловые засечки (CornerTicks), тонкая скан-линия-оверлей.
- **Reveal:** decode/typewriter (шум→буквы) · line-draw (stroke-dashoffset на бордерах/SVG) · scan-wipe между секциями.
- **Hero-процесс:** «консоль обработки» — панель документа сканируется построчно (движется скан-линия); живой лог печатает `→ читаю страницы… → парсинг… → 12 вопросов`; выходная панель собирает карточки теста. Callouts — схематичные аннотации с выносными линиями и «координатами».

### V3 — Cinematic / Gallery (файл `variant-c-cinematic.html`)
- **Шрифт:** дисплей `Bodoni Moda` (400/700/900 + italic, Didone), текст `Archivo` или `Manrope`. Fallback `Georgia, serif` / system-sans для текста.
- **Палитра:** тёплая светлая «галерея». `--bg:#f3f0ea; --ink:#0c0a08; --ink-2:#6a655c; --line:#ddd7cc`. Без цвета; тон несёт контраст и крупные Ч/Б плоскости. (Отличаться от тёмного V2 и холодного V1.)
- **Ритм:** большие планы, максимум негативного пространства, драматичные Ч/Б блоки, «киношная» медленная моторика.
- **Reveal:** параллакс слоёв · scale-rise (0.92→1 + fade) · sticky-пиннинг hero с морфингом.
- **Hero-процесс:** крупный документ, запиненный на скролле, медленно превращается в тест; filmic-темп; callouts — как киношные подписи/тонкие выносные указатели.

## Крафт-правила (планка R13 — из craft-floor impeccable + бриф)

Обязательны во всех вариантах:
- **Контраст:** текст ≥4.5:1, крупный ≥3:1. Вторичный текст — тонировать от фона, не «серый наугад».
- **Пространство:** плотные группы, щедрые разделения; над заголовком больше воздуха, чем под ним; крупный вертикальный шаг между секциями.
- **Типографика:** дисплей крупный (hero может быть очень большим — бриф просит), tracking для крупного до -0.04em; мера текста 65–75ch; реальные строки дека на всех брейкпоинтах, чинить переполнения.
- **Моушен:** один авторский момент (hero-процесс) — оркестрован, а не разбросанные hover'ы; reveal-и не одинаковы на каждой секции; ease-out от уже видимого состояния; всегда `prefers-reduced-motion`.
- **Иконки:** рисованные SVG в штрихе своего мира. НЕ эмодзи, НЕ юникод-глифы.
- **Каждая секция иначе соседней** (R09): менять сетку/масштаб/плотность/приём.
- **Ч/Б приоритет, минимум цветных блоков** (R02). **Мало текста, много воздуха** (R07). **Ведёт визуал** (R08).
- **Адаптив:** 360–1440px, без горизонтального скролла body; тяжёлые scroll-эффекты деградируют на мобильном.
- **Запрещено** (craft-floor): градиентный текст; стекло/блюр как декор; цветной border-left >1px; жёсткие offset-тени без блюра; одинаковые карточки «иконка+заголовок+текст» как структура страницы; kicker/eyebrow над заголовком; номера секций 01/02 без смысловой нагрузки; системный дисплей-шрифт как голос мира.

## Что построили завершённые тикеты

### Тикет 01 — Фундамент (готово)
- `shared/switcher.js` — переключатель + синк скролла. Подключение:
  `<script src="shared/switcher.js" defer>`. Ждёт `<nav data-switcher>`. Ключ
  `sessionStorage['pdfland:scrollRatio']` (доля 0..1). Самоинициализируется (IIFE).
  `scrollRestoration=manual`; восстановление после двойного rAF, при reduced-motion мгновенно.
- `shared/reveal-core.js` — IntersectionObserver (0.15), `.is-in` на `[data-reveal]`
  один раз + unobserve; reduced-motion или нет IO → всем сразу. Подключение:
  `<script src="shared/reveal-core.js" defer>`. Доп. data-атрибуты — на усмотрение мира.
- `index.html` — входная витрина: 3 ссылки-карточки (V1/V2/V3) + `<nav data-switcher>`,
  Ч/Б, Archivo. Оба shared-скрипта подключены defer.

### Тикет 02 — Вариант A / Swiss (готово)
- `variant-a-swiss.html` — self-contained. Подключены оба shared-скрипта + `<nav data-switcher>`.
- Reveal-атрибуты: `data-reveal` (mask-заголовки `.ml>span`), `data-reveal="rise"` (+`--d` стаггер),
  `data-reveal` на `.rule` (hairline-draw) и `[data-count-to]` (счётчики 0→N через MutationObserver на `.is-in`).
  Свой hero-скраб: `--scan/--recog/--build` + `.on` на callouts. Скраб активен ≥900px; ниже и при reduced-motion — статичный финал.

### Тикет 03 — Вариант B / Terminal (готово)
- `variant-b-terminal.html` — self-contained. Подключены оба shared-скрипта + `<nav data-switcher>`.
- Reveal: `[data-reveal]→.is-in` (база), `.draw` (line-draw stroke-dashoffset), `.wipe>.wipe-veil` (scan-wipe),
  свой IO для `data-decode` (typewriter) и `data-card`/`data-callout` (hero scroll-scrub).
- `--ink-2` поднят до `#8b8b85` (контраст ≥4.5:1 на `#0d0d0f`). Сигнальный `#d8ff3e` — только тонкие линии/курсор.

### Тикет 04 — Вариант C / Cinematic (готово)
- `variant-c-cinematic.html` — self-contained. Подключены оба shared-скрипта + `<nav data-switcher>`.
- Reveal: `[data-reveal]` (база), `data-reveal="rise"` (scale 0.92→1+fade), `="parallax"`, `="fade"`; задержки inline `--rd`.
- Hero — единственный запиненный (sticky) морф PDF→тест, 4 фазы, киноподписи. Все планы/иконки — inline-SVG/CSS, офлайн. В SVG-атрибутах литерал `#f3f0ea` вместо var() (Safari).
