# Изначальная задача

> Записано 2026-08-12. Этот файл не редактируется — он эталон, с которым
> сверяется готовый результат.

## Из prompt.md

Создай одностраничный лендинг для рекламы pdf to test.

Стиль:
Сайт должен быть в приоритете черно-белым, без большого количества цветастых блоков

1. В последующих экранах также должан быть scroll-trigger анимация появления некоторых элементов - предложи варианты
2. Главная hero-секция должна иметь скролл-триггер-анимацию, где у нас будет впоследствии сгенерирован процесс перевода pdf to test, в
также на видео будут появляться всплывающие элементы пояснения-указатели некоторых деталей процесса
3. Твоя задача предложить наполненность страницы экранами, какие элементы мы будем использовать внутри

Ограничения:
1. Сайт не должен иметь слишком много текста, должен быть свободным и иметь много воздуха
2. Сайт не должен быть однообразным, иметь много визуала и ацент именно на нем
3. Каждая следующая секция должна отличаться от предыдущей, чтобы не было ощущения монотонности

## Из сообщения к /autopilot

Нам необходимо сделать несколько вариантов этого сайта с возможностью переключения этих вариантов между собой.
Варианты должны быть принципиально разные для того, чтобы можно было потом выбрать лучшую из версий.
Для того, чтобы сайт был визуально красивым, используй скилпак /impeccable
