## Из брифа, дословно
> «как идея эффекты съедания + появления» (референс `.autopilot/chess/refs/10-capture-pop-effects.png` — посмотри: штрихованная клетка с надписью «POP», разлетающиеся крестики/кружки/треугольники)

## Критерии приёмки
- [ ] Взятие: на клетке взятия — короткий (≈450 мс) эффект «хлопка»: штриховка клетки + разлёт 8–12 мелких геометрических частиц (крестики, кружки, треугольники) в цветах набора фигур/доски, взятая фигура «лопается» (scale↑ + fade), надпись не обязательна (иконка-вспышка вместо текста «POP», чтобы не зависеть от языка). Своя отрисовка (SVG/CSS), без библиотек.
- [ ] Появление: фигуры при старте новой партии «вырастают» каскадом по рядам (≈350 мс суммарно), при превращении пешки — вспышка новой фигуры, при откате хода — возвращённая фигура проявляется.
- [ ] Шах — короткая пульсация клетки короля; мат — эффект сильнее (волна по доске).
- [ ] Все эффекты — слой поверх доски `pointer-events:none`, не сдвигают раскладку, не мешают drag; выключаются переключателем анимации (`gw-chess-anim`) и `prefers-reduced-motion`; 60 fps на средней машине (только transform/opacity).
- [ ] Работает на всех досках сайта (игра, задачи, онлайн, звонок, разбор) без правок вызывающих страниц; опционально проп `effects?: boolean` (по умолчанию вкл).
- [ ] Проверено в браузере (взятие, превращение, новая партия, мат), запись/скриншоты `shots/20-*`; все шахматные самопроверки зелёные, tsc/eslint.
