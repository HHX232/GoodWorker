# 06 — Общая шахматная доска в видеозвонке

**Требования:** R08, R09, R10, R22i, R23i, R23i.1, R23i.2

**Зона:** `src/widgets/VideoRoom/` · `app/api/call/rooms/` · `messages/chess/call/`
**Волна:** 2

## Что должно заработать

В звонке с предметом «Шахматы» на панели управления есть кнопка «Шахматы»: она открывает общую доску в главном слоте (как доску-рисовалку). Ходы видят все; опоздавший получает позицию. Владелец звонка решает, кто ходит (все / только я), сбрасывает, ставит позицию из FEN, разворачивает доску у себя; доску можно свернуть и вернуть. В звонке без предмета или с другим предметом кнопки нет.
