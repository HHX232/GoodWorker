# 13 — Управление как на chess.com: модалки «Новая партия» и «Настройки», режимы, шторм задач

**Требования:** G15, G16
**Blocked by:** 11 (огонёк/рейтинг в шапке, stormBest*, activity)
**Зона:** `src/widgets/Chess/Settings/` (модалки) · `src/_pages/Chess/{Play,Hub,Puzzles}/` · `src/_pages/Chess/Storm/` + `app/chess/storm/` · `app/api/chess/storm/` (рекорд) · `messages/chess/{play,core}/` и новая `messages/chess/storm/`
**Волна:** 5

## Из брифа, дословно
> «Как на chess.com сделай удобное управление через модалки, личные настройки, сделай несколько режимов» · ответ: «С ботом (есть), Онлайн с контролем времени, С другом по ссылке, Шторм задач»

Разделы спецификации: «Дополнения 2026-10-19» в .autopilot/chess/spec.md (соответствующий абзац). Ответы пользователя — в брифе, раздел «### 2026-10-19».

## Критерии приёмки
- [ ] Модалка «Новая партия» — вкладки по спеке; «Онлайн» и «С другом» ведут в маршруты T12 (`/chess/online?tc=…` / создание партии через `POST /api/chess/games`) — по контракту, страницы делает T12 параллельно. Модалки: фокус-ловушка, Esc, фон, мобильный bottom-sheet.
- [ ] Модалка «Настройки» — все пункты из спеки; настройки — localStorage (существующие ключи доски/фигур/звука/подсказок переиспользовать), новые — `gw-chess-confirm`, `gw-chess-coords`, `gw-chess-anim`; `ChessBoard` уважает координаты/анимацию (минимальный проп).
- [ ] Страница игры: сверху компактная панель «Новая партия» · «Настройки» вместо россыпи контролов; хаб `/chess` — плитки режимов (Бот, Онлайн, С другом, Задачи, Шторм, Изучать, Курсы) + `<StreakFlame/>` и `<RatingChip/>` из T11.
- [ ] Шторм `/chess/storm`: 3/5 мин, задачи по нарастающей (существующий `/api/chess/puzzles/next` с `minRating`), ошибка −10 с, 3 ошибки — конец, итог/рекорд (`POST /api/chess/storm {mode, score}` → обновляет `stormBest*` и `recordChessActivity('storm')`), гостю — без сохранения.
- [ ] Фикс из ревью: колонка тренера на /chess/play и решебнике — DOM в хронологическом порядке, прокрутка к последней реплике через scrollTop (не column-reverse).
- [ ] Строки 4 локали. Крафт `impeccable`. Проверено в браузере, скриншоты `shots/13-*`.
- [ ] Из ревью 11: `<StreakFlame/>` встроен в шапку шахматного раздела (хаб и страницы игры/задач/шторма) — огонёк виден не только в профиле.
- [ ] Смена уровня бота посреди партии — предлагает начать новую партию (модалка «Новая партия»), а не меняет уровень текущей.
