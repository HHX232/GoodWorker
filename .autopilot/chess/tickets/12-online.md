## Критерии приёмки
- [ ] Модели и логика по спеке. Чистое ядро `online.ts` (применение хода с часами и инкрементом, флаг по времени, все окончания, ничья/сдача/отмена, Эло K=32, подбор с окном) + `online.selfcheck.ts` → `online ok` (кейсы с часами — время задаётся явно).
- [ ] Гонки: два одновременных хода → один принят (проверка `ply` + транзакция/условный update); два seek → одна партия.
- [ ] Права: ход только своей стороной и в свою очередь; гость не может играть онлайн (401) — показывается «войдите».
- [ ] API по спеке; `GET …?since=` дешёвый (без лишних join), клиент опрашивает ~1 с только когда вкладка видима (как чат).
- [ ] Поиск игроков `GET /api/chess/players?q=` + «Вызвать» → партия-приглашение и уведомление существующим механизмом (найди хелпер уведомлений/чата; если чат только учитель↔ученик — используй уведомления).
- [ ] Страницы `/chess/online` (лобби) и `/chess/game/[id]` — раскладка как у `/chess/play` (доска по центру сразу под шапкой; слева игроки+часы, справа ходы/кнопки), доска `ChessBoard` с выбранными доской/фигурами, звук, тренер выключен. Ссылка «играть с другом» копируется в буфер.
- [ ] По завершении — Эло обоих и `recordChessActivity(..., 'online')`; результат и изменение Эло на экране.
- [ ] Проверено двумя сессиями (student@seed.dev и teacher@seed.dev, curl или два контекста браузера): подбор, ходы, часы, сдача, Эло. Скриншоты `shots/12-*`.
- [ ] Из ревью 11: на странице `/chess/profile` (+ `/chess/u/[id]`) — блок «Последние партии» (онлайн, 10 последних: соперник, результат, контроль, изменение Эло) — разрешено минимальное добавление в `src/_pages/Chess/Profile/`.
