**Волна:** 1

## Что должно заработать

Фундамент для всех остальных тасков: в браузере поднимается Stockfish (Web Worker), умеет сделать ход по уровню 1–8 и выдать MultiPV-анализ; есть доска `<ChessBoard>` с drag и клик-клик, анимацией хода, стрелками, подсветкой последнего хода и шаха, пикером превращения и координатами; классический скин и реестр скинов (остальные 4 id пока указывают на классику — их нарисует таск 03); звук хода; клиентский тренер: `useMoveCoach` (классификация хода движком, вызов `/api/chess/coach`), `CoachPanel`, `EvalBar`. Проводка i18n `chess.*`.

## Из брифа, дословно

> «Модель с разными уровнями сложности, можешь найти на гитхабе готовую.»
> «режим бесплатного ИИ тренера, который будет комментировать ходы, объяснять какой и почему лучше, но тут нужен реально хороший модель для рассчета, который в свою очередь через дипсик тот же обхяснит нормальным понятным языком кратко что зачем и почему»

## Критерии приёмки

- [ ] Разрешено поставить ОДНУ зависимость: `npm i -D stockfish@19` (github.com/nmrugg/stockfish.js, GPL-3). В `public/stockfish/` попадает только lite single-thread сборка (js + wasm, ~7 МБ) — скриптом `scripts/copy-stockfish.mjs`, подключённым в `postinstall` (или `prebuild`), + `public/stockfish/LICENSE.txt` (GPL-3 текст из пакета) и `README` со ссылкой на исходники. Не требует COOP/COEP.
- [ ] `getEngine()` — ленивый синглтон; `bestMove` по таблице уровней из spec («Дополнения после G2»); `analyse` с MultiPV; параллельные вызовы встают в очередь, а не ломают протокол; сбой загрузки → `ENGINE_UNAVAILABLE`.
- [ ] `coachModel` по контракту + `coachModel.selfcheck.ts` печатает `coachModel ok` (кейсы: лучший ход, потеря 80 → inaccuracy, зевок ферзя → blunder, пропущенный мат, ход при уже матовой оценке).
- [ ] `<ChessBoard>` по контракту: квадратная, тянется по ширине контейнера (на 360px без горизонтального скролла), ход анимируется ≤ 200 мс, недопустимый ход возвращает фигуру, превращение — пикер, работает мышью и тачем; доступность: клетки — кнопки с aria-label («e4, белый конь»), ход стрелками+Enter.
- [ ] Классический скин нарисован (стаунтон-силуэты, доска `#f0d9b5`/`#b58863`); `SKINS` содержит все 5 id; `useChessSkin` синхронизирует все доски на странице.
- [ ] `useMoveCoach().review` даёт `MoveReview` (MultiPV 3, ~1 с/глубина ≥ 14 до хода и оценка после); `explain` зовёт `/api/chess/coach` (контракт в interfaces; сервер пишет таск 02 — до его готовности 404 обрабатывается как `UNAVAILABLE`); `CoachPanel` показывает класс хода цветом+текстом, лучший ход, «Почему?», текст объяснения, состояния LIMIT (гость: «войдите — лимит больше»; user: «с VIP — без лимита»), UNAVAILABLE.
- [ ] `EvalBar` (A01) и звук (A02, WebAudio без файлов, выключатель).
- [ ] i18n: `request.ts` собирает `chess` из `messages/chess/<area>/<locale>.json` (area core/play/learn/call/course; пустые `{}` создать для всех), строки этого таска — в `core`, 4 локали.
- [ ] Временная демо-страница НЕ создаётся в `app/` — проверь в браузере через существующую `/game/chess`, подменив в ней доску на `<ChessBoard>` + ход движка (страницу полностью переделает таск 04 — достаточно минимальной подмены, которая работает).
