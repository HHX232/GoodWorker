## Критерии приёмки
- [ ] `reviewModel.ts` (чистый): win%, классификация по правилам спеки (все 10 классов), точность, счётчики, ключевые моменты; `reviewModel.selfcheck.ts` → `review ok` — ожидания разобраны вручную: книжный ход, лучший, жертва ферзя с матом (блестящий), единственный спасающий ход (отличный), неточность/ошибка/зевок по порогам, упущение после зевка соперника, точность при нулевой и большой потере.
- [ ] Страница `/chess/analysis`: принимает `sessionStorage['gw-chess-analysis']`, `?game=<id>` (онлайн — `GET /api/chess/games/[id]`, по контракту T12; если 404 — понятная ошибка) и вставку PGN (поле); прогон движком с прогресс-баром и отменой (cancelAll при уходе/новом разборе, паттерн поколений из interfaces.md).
- [ ] Отображение: карточка «Точность» обеих сторон + счётчики классов с иконками; график оценки; список ходов с иконками классов; на доске — значок класса в углу клетки назначения и стрелка лучшего хода; листание стрелками клавиатуры; фильтр ключевых моментов; тренер (CoachSays) объясняет выбранный ход по кнопке (реальные данные разбора, context 'game').

- [ ] Раскладка как у /chess/play (доска по центру под шапкой; слева тренер/карточка точности, справа ходы/график); 375px и тёмная тема.
