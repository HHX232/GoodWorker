## Критерии приёмки

- [ ] `vintage.tsx`, `night.tsx`, `bordo.tsx`, `powder.tsx` по контракту `SkinDef` (interfaces.md), каждая фигура — компонент inline-SVG, `viewBox` 0 0 100 100, читается на размере клетки 40px.
- [ ] Белые и чёрные фигуры каждого набора различимы на обеих клетках своей доски (контраст проверен глазами на скриншоте).
- [ ] Единый язык формы в наборе: общий постамент, общая толщина линий; «Винтаж» и «Пудра» — фигуры с профилями лиц; «Бордо» — короны как мотив; «Ночь» — плоские монохромные силуэты.
- [ ] Это собственный рисунок, не трассировка референсов (Vexels — чужая работа).
- [ ] Скриншот доски в начальной позиции для каждого скина — `.autopilot/chess/shots/skin-<id>.png` (через страницу, где стоит `<ChessBoard>`, см. interfaces «Из таска 01»).
- [ ] tsc/eslint чисто.
