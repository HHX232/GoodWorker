**Волна:** 1

## Что должно заработать

В БД есть задачи (≈50 000 из открытой базы Lichess, CC0), рейтинг задач ученика и история решений; на платформе есть предмет «Шахматы» (категория `chess` с переводами ru/en/hi/zh — значит он сам появится в создании звонка и в курсах). Работают `POST /api/chess/coach` (DeepSeek объясняет ход по фактам движка, с лимитами гость/вошёл/VIP) и API задач/прогресса.
