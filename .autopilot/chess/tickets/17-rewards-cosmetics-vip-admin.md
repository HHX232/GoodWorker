# 17 — Все боты сразу, награды-скины и раскраски доски, VIP за значки из админки

**Требования:** G23, G24, G25
**Blocked by:** —
**Зона:** `src/shared/lib/chess/data/bots.ts` · `src/widgets/Chess/skins/` (новые наградные наборы/доски + метаданные `unlock`) · `src/widgets/Chess/Board/SkinPicker.*` (замки) · `src/shared/lib/chess/server/{progressModel,progress}.ts` (VIP из настроек) · `prisma/` (свой блок в конец + миграция) · `app/api/admin/chess/` · админка: раздел настроек шахмат (найди админку `app/admin`, по образцу «Хранилище» — `app/api/admin/storage`) · `messages/chess/{core,progress}/` + admin-строки (по паттерну админки)
**Волна:** 7

## Из брифа, дословно
> «уровни ботов надо давать сразу все» · «придумай награды скины, награды раскраску полей» · «дней вип поставь 5, но в админке чтоб менялось»

## Критерии приёмки
- [ ] Все 13 ботов доступны сразу всем (замки спец-ботов сняты, `unlock` у ботов убран; откат «закрытого бота» на странице игры больше не нужен — убери ветку).
- [ ] Награды-косметика: минимум 4 новых наградных набора фигур и 4 раскраски доски (придумай сам, в духе раздела: напр. «Золото» за points_1000, «Неон» за storm_20, «Мрамор» за streak_30, «Ночная сетка» за first_win_l8; раскраски — «Лёд», «Изумруд», «Закат», «Графит»), свои SVG/цвета, читаемость белых/чёрных на всех досках. Каждый — `unlock: badgeCode`. Существующие 6 наборов/досок открыты всем.
- [ ] `SkinPicker`: закрытые с замком и подписью «Откроется: …», выбрать нельзя; гостю закрыты все наградные. Проверка по значкам из `/api/chess/profile/me`; сервер не нужен (косметика), но выбранный закрытый скин из localStorage откатывается на классику.
- [ ] Тост «Новый значок!» показывает и открытую награду (скин/доску/VIP-дни).
- [ ] VIP: настройки наград в БД (`ChessSettings` — одна строка, `vipRewards Json` `{badgeCode: days}`), по умолчанию `{points_1000: 5, points_5000: 5, streak_30: 5}`; `progress.ts` берёт таблицу из БД (кэш ≤ 60 с), а не из константы. Правило: в админке можно назначить VIP только значкам из разрешённого списка (`points_*`, `streak_*` — ограничены дневным потолком; `online_first_win`/`storm_*` — запрещены, пока нет антифарма) — серверная валидация.
- [ ] Админка: раздел «Шахматы → Награды» — список значков с полем «дней VIP» (0 = выкл.), сохранить; `GET/PATCH /api/admin/chess/settings` (только админ, валидация 0–365).
- [ ] selfcheck: таблица из настроек, запрещённые значки отклоняются, 0 = нет начисления; существующие самопроверки зелёные.
- [ ] Миграция руками, применена локально (db execute + resolve + generate); после generate — сообщи, dev-сервер перезапустит оркестратор.
- [ ] Строки 4 локали; проверено в браузере (выбор скинов с замками, админка), скриншоты `shots/17-*`.
