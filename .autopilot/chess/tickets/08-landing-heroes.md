## Что должно заработать

Три статических HTML-прототипа первого экрана (и короткого продолжения под ним: 3–4 блока возможностей), между которыми переключаешься одним кликом. По ним пользователь выберет Hero для боевого лендинга.

> «максимально круто»

## Критерии приёмки

- [ ] Файлы `chess-hero-a-live.html` («Партия идёт»: живая доска — заранее записанная партия проигрывается сама, рядом реплики тренера появляются по ходам; класс хода цветом), `chess-hero-b-gallery.html` («Галерея скинов»: крупные фигуры-персонажи, бордо/крем позитив-негатив как в референсах 3–4, переключение скина меняет сцену), `chess-hero-c-explain.html` («Разбор зевка»: одна позиция, стрелка зевка → стрелка лучшего хода, полоса оценки падает, фраза тренера печатается).
- [ ] Инлайн-свитчер одинаковой разметки во всех трёх: `<nav data-chess-switcher aria-label="Варианты Hero"><a data-hero="a" href="chess-hero-a-live.html">A</a>…</nav>`, активная ссылка `aria-current="page"` по имени файла.
- [ ] Один копирайт во всех трёх (H1, подзаголовок, CTA «Играть с тренером» / «Решать задачи», 4 пункта возможностей: движок 8 уровней, ИИ-тренер объясняет ходы, 50 000 задач, доска в видеозвонке с репетитором) — байт-в-байт одинаковые строки.
- [ ] Правила прототипов из `CLAUDE.md` (раздел «PDF → Тест — прототипы»): только HTML/CSS/vanilla JS инлайн, только Google Fonts с fallback, без CDN-скриптов; фигуры — собственный inline-SVG, не копия Vexels; `prefers-reduced-motion` → без движения; 360–1440px без горизонтального скролла.
- [ ] Крафт — скилл `impeccable`; без эмодзи.
- [ ] Снят desktop-скриншот каждого (headless Chrome, ширина ≥ 500px) в `.autopilot/chess/shots/`.
