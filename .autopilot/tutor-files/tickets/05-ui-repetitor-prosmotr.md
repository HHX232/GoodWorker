## Что должно заработать

VIP-репетитор открывает вкладку «Файлы» в своём дашборде и видит библиотеку: слева — компактное дерево папок для быстрой навигации, справа — хлебные крошки, строка глобального поиска, сетка карточек папок/файлов. Может создать папку, переименовать, удалить (папку — вместе со всем содержимым), загрузить файл, открыть предпросмотр PDF/картинки без скачивания. Не-VIP репетитор видит вместо содержимого заглушку-апсейл.

- `src/widgets/Files/FilesShell/FilesShell.tsx` — принимает `role: 'teacher' | 'student'` (в этом тикете используется только `role="teacher"`, `role="student"` — задел под тикет 07). Каркас: сайдбар-дерево + хлебные крошки + поиск + сетка. На узких экранах дерево сворачивается в выпадающее меню.
- `FolderCard`/`FileCard` — карточки по референсу (скруглённые, светлая палитра, счётчик вложений на папке), в компонентах/палитре GoodWorker; тёмная тема — блок `:global(html.theme-dark)` в конце `*.module.scss`.
- `FilePreviewModal` — для `mimeType` начинающихся с `image/` и `application/pdf` — встроенный просмотр (`<img>`/`<iframe>` на публичный S3 URL); остальные типы — сразу скачивание по прямой ссылке.
- Создание/переименование/удаление папки, загрузка файла — вызывают API из тикета 02; после успешной загрузки, если `usedBytes > QUOTA_BYTES` (импорт из `tutorFiles/storage`) — здесь ТОЛЬКО фиксируется факт (модалку показывает тикет 06, но точку вызова — «показать модалку» — оставить как понятный хук/проп в месте, куда 06 её добавит).
- `src/widgets/Files/icons.tsx` — плоский реэкспорт `lucide-react`, по образцу `src/widgets/Chat/icons.tsx`.
- VIP-гейт: если `!teacher.isVip` (или `vipExpiresAt` истёк) — вкладка рендерит заглушку с предложением оформить VIP вместо `FilesShell`.
- Подключение вкладки «Файлы» в дашборд репетитора — там же, где уже переключаются существующие вкладки (`DashboardCenter` или её текущий механизм табов — использовать существующий, не изобретать новый).
- `messages/{en,hi,ru,zh}.json` — namespace `files`: базовые ключи (заголовок вкладки, пустое состояние, кнопки создать/загрузить/удалить/переименовать, заглушка не-VIP, поиск).

## Критерии приёмки

- [ ] Вкладка «Файлы» видна и открывается из дашборда репетитора
- [ ] Пустая библиотека показывает приглашение загрузить файл/создать папку, не голую сетку
- [ ] Не-VIP репетитор видит заглушку-апсейл вместо содержимого
- [ ] Создание папки на 7-м уровне вложенности показывает понятную ошибку (используя ответ API тикета 02)
- [ ] Клик по PDF/изображению открывает предпросмотр без перехода/скачивания; клик по другому типу — скачивание
- [ ] Поиск находит папку/файл по части названия в любом месте дерева
- [ ] Вкладка проходит смоук в светлой и тёмной теме, без горизонтального скролла на узких экранах, дерево сворачивается
