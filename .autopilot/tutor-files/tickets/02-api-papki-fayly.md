# 02 — API: папки, файлы, загрузка, удаление

**Требования:** R01i, R01i.1, R02.1, R02.2, R07i, R08i, R08i.1
**Blocked by:** 01
**Зона:** `app/api/tutor-files/folders/`, `app/api/tutor-files/files/`
**Волна:** 2
**Status:** ready

## Что должно заработать

Репетитор через API может: создать папку (с проверкой глубины ≤ 6 через `MAX_FOLDER_DEPTH`), переименовать папку, загрузить файл в папку или в корень, удалить файл, удалить папку целиком (каскадно — вложенные папки, файлы и **все** гранты на них пропадают вместе с ней).

- `POST /api/tutor-files/folders` — `{name, parentId?}` → создаёт `TutorFolder`, вычисляет `ancestorIds` от родителя, отклоняет с понятной ошибкой, если `parent.ancestorIds.length + 1 >= MAX_FOLDER_DEPTH`.
- `PATCH /api/tutor-files/folders/[id]` — переименование (`requireOwnedFolder`).
- `DELETE /api/tutor-files/folders/[id]` — каскадное удаление через `onDelete: Cascade` в схеме (проверить, что удаление родителя действительно снимает дочерние `TutorFolder`/`TutorFile`/гранты — если Prisma/Postgres не даёт каскад на self-relation, удалять рекурсивно в транзакции).
- `POST /api/tutor-files/files` — принимает `FormData` с файлом + `folderId?`; вызывает существующий `uploadFile()`-эквивалент на сервере (`uploadFilesToS3` или прямой вызов `app/api/upload`-логики с `folder: 'tutor-files'`) — **не менять** `app/api/upload/route.ts`; пишет `TutorFile`; возвращает `{file, usedBytes}` (контракт — `interfaces.md`, раздел «Контракт между тикетами: квота»).
- `DELETE /api/tutor-files/files/[id]` — удаляет файл и его гранты.

Все эндпоинты — только для `TEACHER` (через `getFilesSessionUser()`), 403 на чужую папку/файл.

## Критерии приёмки

- [ ] Создание папки на 6-м уровне проходит, на 7-м — отклоняется с понятным сообщением
- [ ] Загрузка файла создаёт `TutorFile` с корректным `sizeBytes`/`mimeType`/`url`, ответ содержит актуальный `usedBytes`
- [ ] Удаление папки с вложенными файлами/подпапками/грантами не оставляет «сирот» в БД (проверить прямым запросом после удаления)
- [ ] Попытка репетитора A обратиться к папке/файлу репетитора B — 403
- [ ] Ошибка загрузки (сеть/размер) возвращает понятный текст, `TutorFile` не создаётся «наполовину»
