## Что должно заработать

Репетитор открывает модалку расшаривания с карточки папки/файла, выбирает одного или нескольких своих учеников (мультивыбор), включает/выключает на папке «ученики могут сдавать сюда». После загрузки файла, впервые переведшей его за 7 ГБ, видит информационную модалку о будущей ежемесячной плате.

- `ShareAccessModal` — список учеников репетитора (те же, что видны в существующих местах выбора ученика — переиспользовать паттерн, не писать новый эндпоинт списка учеников, если такой уже есть в проекте), чекбоксы, кнопка «Открыть доступ» → `POST /api/tutor-files/grants` (тикет 03). Для папки — тумблер «Ученики могут сдавать сюда» → `PATCH` поля `allowStudentUpload`. Список уже открытых доступов на элементе — с кнопкой отзыва у каждого → `DELETE /api/tutor-files/grants`.
- `StorageOverageWarningModal` — по образцу портала `InsufficientBalanceModal` (`createPortal` в `#modal_portal` с фолбэком на `document.body`, `stopPropagation` на закрытии, чтобы не закрыть родительскую модалку). Показывается один раз при первом переходе через `QUOTA_BYTES` (не при каждой последующей загрузке в этом же перелимите — проверять по факту «был ли `usedBytes` уже больше `QUOTA_BYTES` до этой загрузки»). Текст — сколько ГБ сверх лимита и по какой цене за ГБ/мес (`GET /api/tutor-files/usage`, поле `priceCentsPerGbMonth`; если `0` — текст «стоимость пока не назначена» вместо суммы). Ссылка на `/wallet`.

> «лимит фиксированный, если превышает лимит то идет снятие денег со счета» (ответ на брифинге, G02) + «загрузил файл сверх лимита — сразу показываем уведомление модалкой, но списываем раз в месяц в конце месяца» (ответ на брифинге)

## Критерии приёмки

- [ ] Мультивыбор нескольких учеников в одной отправке даёт доступ всем выбранным
- [ ] Тумблер «ученики могут сдавать» переключается и сохраняется
- [ ] Отзыв доступа из модалки убирает ученика из списка немедленно (по возврату API)
- [ ] Загрузка, впервые превысившая 7 ГБ, показывает предупреждение; повторная загрузка при уже существующем перелимите — не показывает его снова
- [ ] Модалка предупреждения не закрывает случайно родительскую модалку/карточку при клике внутри себя
- [ ] При цене `0` (заглушка ещё не заполнена) модалка не показывает выдуманную сумму
