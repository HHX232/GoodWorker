# Спецификация: блок промо-видео для главной — 4 варианта

## Задача
На главной GoodWorker (`app/page.tsx` → `LandingPage`) нужен блок, в котором открывается видео о компании. Блок должен быть **максимально низким**, чтобы встать между существующими крупными секциями, не раздувая страницу. Нужно несколько вариантов дизайна под стиль главной; у каждого — своя визуальная фишка и своя функциональная фишка.

## Решение
Один статический файл-витрина `ForNewDesign/prototypes/promo-video-variants.html` (дизайн-разведка, как остальные прототипы в этой папке). В нём 4 варианта блока, каждый показан «в контексте»: над и под ним — серые заглушки-силуэты соседних секций главной, чтобы было видно, как блок ложится в страницу. Над каждым вариантом — служебная подпись (буква, название, высота в свёрнутом виде, одна строка «внешняя фишка», одна строка «функциональная фишка»). Сверху витрины — компактное оглавление-якоря A/B/C/D.

### Видео (R01)
«Видео о компании» в репозитории — это два ролика в `promo-videos/optimized/` (других промо-видео в проекте нет); оба квадратные 1:1:
- Репетиторам — `../../promo-videos/optimized/GoodWorker_Teachers_v5_720.webm` / `.mp4`, постер `GoodWorker_Teachers_v5_1080.jpg`, 0:40.
- Ученикам — `../../promo-videos/optimized/GoodWorker_Students_720.webm` / `.mp4`, постер `GoodWorker_Students_1080.jpg`, 0:35.
Каждый `<video>`: `<source>` webm, затем mp4; `playsinline`, `preload="metadata"` (кроме мини-превью, где нужно — `preload="auto"` допустим только для видимого превью). Пути относительные — работает при открытии файла по `file://` из `ForNewDesign/prototypes/`.
Каждый вариант даёт выбрать любой из двух роликов (способ выбора — часть фишки варианта).

### Четыре варианта (R03, R07, R08)

**A — «Кружок»** · высота ≤ 96px.
- Внешняя: горизонтальная полоса-строка; слева круглое «видео-сообщение» диаметром 72px (как кружок в Telegram), внутри — беззвучное зацикленное превью ролика; вокруг кружка — тонкое кольцо-прогресс (SVG). Справа от кружка — заголовок в Russo One одной строкой + подпись с длительностью; справа в строке — две пилюли-переключателя «Репетиторам · 0:40» / «Ученикам · 0:35».
- Функциональная: клик по кружку — кружок плавно «вырастает» из своей позиции в центральный круглый плеер (≈ min(80vh, 520px)) поверх затемнённой страницы, играет со звуком с начала; кольцо по краю показывает прогресс, клик по кольцу — перемотка в точку (угол → время); клик по кругу — пауза/плей; Esc / клик по фону / крестик — закрыть, круг «садится» обратно в строку. Переключатель пилюль меняет ролик и в превью, и в плеере.

**B — «Плёнка»** · высота ≤ 120px.
- Внешняя: кино-лента во всю ширину контейнера — ряд кадров ролика (≈ 10–14 кадров, вычисляются на лету: скрытый `<video>` seek → кадр рисуется в `<canvas>`), сверху и снизу перфорация (CSS-паттерн), под лентой — шкала таймкодов 0:00…0:40. Слева от ленты — узкая колонка: заголовок + табы роликов.
- Функциональная: ховер-скраб — при движении курсора по ленте вертикальная красная линия-курсор и над ней маленький тултип с таймкодом; клик по любой точке ленты открывает плеер (модалка 1:1) **с этого момента**. На тач-устройствах — тап по кадру = открыть с этого момента. Пока кадры не готовы — плейсхолдер-шиммер кадров (лента не схлопывается по высоте). Если отрисовка кадров не удалась (например, видео не загрузилось) — в ленте остаётся постер, повторённый плиткой, и функция «открыть с момента» продолжает работать по пропорции ширины.

**C — «Две двери»** · высота в свёрнутом виде ≤ 140px.
- Внешняя: полоса из двух «дверей» рядом — «Я репетитор» и «Я ученик», каждая — тёмная (`#0e0e12`) карточка с постером ролика, обрезанным в широкую полоску и приглушённым; при ховере дверь расширяется (flex-grow), вторая сужается, постер проявляется, на расширенной появляется кнопка «Смотреть · 0:40».
- Функциональная: раскрытие **на месте**, без модалки — клик по двери плавно увеличивает высоту блока (анимация height) до квадратного плеера ролика (≈ 420px, с ограничением по ширине), вторая дверь сжимается в узкую вертикальную вкладку сбоку (кликом по ней — переключение на другой ролик без сворачивания). Кнопка «Свернуть» возвращает блок к исходным ≤140px и ставит паузу. Позиция просмотра каждого ролика запоминается на время сессии страницы: при повторном открытии продолжает с того места, на двери в свёрнутом виде — тонкая полоска «просмотрено N%».

**D — «Строка + мини-плеер»** · высота ≤ 64px.
- Внешняя: самая тонкая — одна строка с хайрлайнами сверху/снизу: слева «живой» индикатор — 5 полосок-эквалайзера (анимируются только когда видео играет), текст «Посмотрите, как работает GoodWorker», справа сегментированный переключатель «Репетиторам / Ученикам» и кнопка-плей.
- Функциональная: плей запускает видео в мини-плеере, который **отделяется от строки и докается в правый нижний угол** экрана (≈ 240×240, на мобильном ≈ 160×160) и продолжает играть, пока пользователь скроллит главную дальше. У мини-плеера: пауза, звук вкл/выкл, «развернуть» (увеличивает до ≈ 420px), «закрыть»; кнопка нативного Picture-in-Picture показывается только если `document.pictureInPictureEnabled`. Мини-плеер можно перетащить мышью/пальцем к любому углу — при отпускании прилипает к ближайшему углу. Строка в потоке, пока мини-плеер открыт, показывает состояние «Смотрите в углу экрана · 0:12 / 0:40» (живое время).

### Пользовательские истории
1. Посетитель листает главную, видит низкую полосу с видео, понимает за секунду, что это ролик о сервисе и сколько он длится.
2. Посетитель запускает ролик — видео играет со звуком (запуск по клику — жест пользователя, звук разрешён).
3. Посетитель выбирает ролик под себя (репетитор / ученик).
4. Посетитель закрывает/сворачивает видео и продолжает листать — страница не прыгает непредсказуемо (в A/B/D высота блока в потоке неизменна; в C изменение высоты — анимированное и вызвано кликом).
5. Дизайнер открывает витрину, сравнивает 4 варианта в контексте страницы и выбирает.

## Решения по реализации
- **Стиль главной (R05, R06):** белый фон `#fff`; чернила `#0e0e12`; серый текст `#5a5a64` / `#8c8c98`; хайрлайны `#ececf2`; акцент только `#ED0606`; заголовки — `'Russo One', system-ui, sans-serif` (Google Fonts через `<link>`), остальной текст — системный стек `system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`; кнопки скруглены 14px (мелкие — 8px), как `.btn_dark`/`.btn_red` главной; эйбрау — 12px, 600, `letter-spacing: .12em`, uppercase, красный. Контейнер витрины — `max-width: 1320px; padding: 0 48px` (≤900px — `0 20px`), как `.container` главной.
- **Бюджет высоты (R04):** свёрнутая высота каждого блока на desktop не превышает заявленную (A 96, B 120, C 140, D 64 px); на мобильном (≤600px) допускается рост не более чем в 2 раза за счёт переноса строк. Раскрытое состояние (видео открыто по клику) в бюджет не входит, но у C, где рост идёт в потоке страницы, раскрытая высота ограничена `min(420px, 70vh)`. Фактическая свёрнутая высота выводится в служебной подписи варианта живым замером (`getBoundingClientRect().height`, обновляется на resize).
- **Мобильная (R10i):** 360–1440px без горизонтального скролла `body` (`overflow-x: hidden` на body). A: пилюли уходят под заголовок. B: на ≤600px колонка заголовка встаёт над лентой, кадров меньше (≈6). C: на ≤600px двери остаются рядом (по 50%), текст укорачивается, ховер-расширение выключено; раскрытый плеер — на всю ширину. D: текст укорачивается до «Видео о GoodWorker», мини-плеер 160px.
- **Иконки:** рисованные inline-SVG (play, pause, звук, развернуть, закрыть, PiP) единым штрихом 1.75–2px; не эмодзи и не юникод-глифы.
- **Модалка плеера (A, B):** `role="dialog"`, `aria-modal="true"`, фокус переносится на плеер/кнопку закрытия и возвращается на исходный элемент после закрытия; Esc закрывает; скролл body блокируется на время открытия. При закрытии видео ставится на паузу.
- **Доступность:** все кликабельные элементы — `<button>` с `aria-label`; переключатели роликов — `aria-pressed` или `role="tab"`; видимый `:focus-visible`.
- **Reduced motion:** при `prefers-reduced-motion: reduce` — без анимаций роста/перелёта/эквалайзера/шиммера (мгновенные переходы), беззвучные автопревью (кружок A) не автоплеят — показывают постер.
- **Автоплей превью:** только `muted` + `playsinline` + `loop`, и только когда блок в viewport (IntersectionObserver), иначе пауза — чтобы витрина не крутила 4 видео одновременно.
- **Без зависимостей:** только HTML/CSS/vanilla JS инлайн в одном файле, без CDN-скриптов, без сборки; Google Fonts — единственная внешняя ссылка, с фолбэком.
- **Ошибки:** если видео не загрузилось (`error` на `<video>`) — в плеере показывается постер и строка «Видео не загрузилось», блок остаётся целым по высоте.

## Границы и швы
Один файл, один исполнитель; общий для всех вариантов модуль — маленький JS-объект `VIDEOS` (два ролика: id `teachers`/`students`, подпись, длительность, src webm/mp4, постер) и, при желании, один общий модальный плеер для A и B. Ничего вне `ForNewDesign/prototypes/promo-video-variants.html` не создаётся и не меняется (Next.js-приложение не трогаем, `promo-videos/` только читаем).

## Вне рамок
- Встраивание выбранного варианта в `LandingPage.tsx` (React/SCSS-модуль, i18n в 4 локали, порядок секций в `audience.ts`) — отдельный шаг после выбора варианта пользователем.
- Аналитика просмотров, субтитры.

## Открытые места
- Тексты в блоках («Посмотрите, как работает GoodWorker», «Я репетитор», «Я ученик» и т.п.) — черновой UI-копирайт; финальные формулировки пользователь может заменить.
