# 02 — Страница чата: список диалогов и адаптивный каркас

**Требования:** R05, R06, R06.1, R08, R08i
**Blocked by:** 01
**Зона:** `app/(...)/chats/` (новый роут — выбери сегмент по конвенции соседних роутов teacher/student), `src/widgets/Chat/ChatShell/`, `src/widgets/Chat/ConversationList/`
**Волна:** 2
**Status:** ready

## Что должно заработать

Страница `/chats` — заходит и репетитор, и ученик (роль определяет, чьи
диалоги показывать). Слева список диалогов с живым поиском по имени
собеседника, справа — область под диалог (сам диалог рисует тикет 03, здесь
пока достаточно плейсхолдера «выбери диалог слева» + правильного каркаса).
На большом экране — не более 2200×1400, по центру, с рамкой/тенью за
пределами; на телефоне — список и диалог как отдельные полноэкранные виды.

## Критерии приёмки

- [ ] `/chats` доступна и репетитору, и ученику, список диалогов реально
      приходит с сервера (curl-проверка тем же способом, что в тикете 01,
      плюс визуальная — через реальный dev-сервер)
- [ ] Поиск по имени собеседника — мгновенный клиентский фильтр, без запроса
      на сервер
- [ ] Пустой результат поиска — понятная подпись, не пустой список
- [ ] Список диалогов, когда их вообще нет — заглушка «Диалогов пока нет»,
      не пустой белый экран
- [ ] На широком экране контейнер чата ограничен 2200×1400, центрирован, с
      видимой рамкой/тенью за пределами (проверить реальным ресайзом окна
      браузера, не только в коде)
- [ ] На ширине < 768px — список и (плейсхолдер) диалог показываются по
      очереди, не сжатыми колонками
- [ ] Тёмная и светлая тема — по конвенции проекта (`:global(html.theme-dark)`)
- [ ] Компонент(ы), которые тикет 03 будет использовать для встраивания
      диалога в правую панель, и их пропсы дописаны в `interfaces.md` под
      «Контракт ChatWidget»
- [ ] Коммит только своих файлов, `git push origin main`
