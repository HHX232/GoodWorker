# Бриф — Баланс/кошелёк вместо прямой покупки VIP

Дословно из диалога (сведено из нескольких сообщений пользователя подряд, порядок сохранён):

> Короче, вместо покупки VIP создать пополнение счета собственного, где при пополнении от 5 долларов выдается вип на месяц, и так за каждые 5 баксов условно, за всякие ИИ фичи мы снимаем стоимость + проценты. Но только как реализовать пополнение без покупки вип...

> вип, по сути остается ВИП - кол-во юзеров в звонке, наличие сосбственных курсов, сколько учеников и так далее решает галочка вип
> Использование большого числа участников в звонке токены не съедает
> Съедают именно запросы AI - тесты, формулы, домашка - но определение ошибок после видеозвонка это не платно, это бесплатно, остальное ИИ платно (отобрази список и предоставь выбор мне)
> Я бы хотел сделать полнстью функционал - мок оплата (пополнение баланса), отображение баланса, обработка потраченных средств на ИИ и снятие их со счета
> /ponytail /autopilot

Уточнение платёжного провайдера обсуждалось отдельно (bePaid.by / webpay.by) — по итогам пользователь явно сузил текущий объём до **мок-оплаты**, интеграция реального провайдера отложена на отдельный заход и в этот бриф не входит.

## Решения, уже принятые в диалоге до старта автопилота (не переспрашивать)

- VIP остаётся отдельной булевой характеристикой аккаунта (лимит участников звонка, свои курсы, число учеников и т.п.) — баланс НЕ тратится на эти фичи, это два независимых механизма.
- Пополнение баланса — **мок**: без реального платёжного провайдера, интеграция считается будущей отдельной задачей.
- Пополнение от $5 даёт VIP на месяц, "за каждые 5 баксов условно" — т.е. `floor(сумма / 5)` месяцев VIP начисляется поверх текущего срока; вся внесённая сумма при этом полностью идёт в баланс (VIP — бонус сверху, не списание с депозита).
- Список из 7 AI-эндпоинтов проверен по коду и подтверждён пользователем как полностью платный, без исключений (ответ на прямой вопрос с выбором):
  1. `app/api/whiteboard/formula-ai/route.ts` — формула по текстовому описанию
  2. `app/api/whiteboard/formula-photo/route.ts` — формула по фото
  3. `app/api/pdf-to-test/route.ts` — PDF → Тест (публичный продукт)
  4. `app/api/pdf-to-test/photos/route.ts` — PDF → Тест по фото
  5. `app/api/tests/import-pdf/route.ts` — импорт теста из PDF (банк вопросов учителя)
  6. `app/api/teacher/lesson-plan/route.ts` — генерация плана урока
  7. `app/api/teacher/lesson-plan/revise/route.ts` — доработка плана урока
- `app/api/call/analyze-errors/route.ts` (разбор ошибок после видеозвонка) — явно бесплатно, биллингом не трогать.
- Формула стоимости — "себестоимость + проценты" (наценка), единая для всех 7 эндпоинтов; точный процент/тариф пользователь не называл — решается в спецификации, вынести в одно место (константы), не хардкодить по роутам.
