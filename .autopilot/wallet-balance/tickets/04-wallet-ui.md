## Что должно заработать

Любой залогиненный (TEACHER/ADMIN/STUDENT) видит компактный бейдж баланса в хедере рядом
с `ChatHeaderIcon`/`NotificationBell`, кликабельный на страницу `/wallet`. Там — крупно
текущий баланс, форма мок-пополнения (сумма в долларах, шаг $1, подсказка «от $5 — плюс
месяц VIP»), и список истории транзакций (пополнения и списания по AI-фичам, человеко-
читаемые названия эндпоинтов, не сырые URL). У нового пользователя без единого пополнения —
«$0.00 · Пополнить баланс», история — «Пока пусто».

Строится строго против контракта `/api/wallet/*` из `interfaces.md` — бэкенд уже есть
(тикет 01), эта работа только про фронтенд.
