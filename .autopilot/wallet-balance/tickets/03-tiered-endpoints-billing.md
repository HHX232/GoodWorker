## Что должно заработать

Два эндпоинта, у которых VIP сегодня не блокирует доступ целиком, а расширяет лимит
(страницы 5→50, форматы PDF→+DOCX/TXT/RTF/ODT) — эта тарифная логика **не меняется вообще**.
Поверх неё добавляется списание с баланса, но только для залогиненных пользователей:
анонимный гость (`pdf-to-test`, `isGuest`) как пользовался бесплатным путём (≤5 страниц
PDF) без всякого биллинга, так и продолжает — гостя эта фича не касается никак, у него нет
ни аккаунта, ни баланса.

Для залогиненного (VIP или нет — тариф уже решил, сколько ему можно обработать) —
preflight по оценке стоимости, вызов, списание реальной стоимости после успешного ответа.
Существующие 403/400 ответы тарифной логики (формат не тот, гость просит DOCX, страниц
больше лимита) остаются как есть и идут раньше проверки баланса — баланс не должен
блокировать то, что и так не прошло бы по тарифу.

## Критерии приёмки

- [ ] `pdf-to-test`: гостевой путь (`isGuest === true`) — без изменений, никакого обращения к `wallet`-модулю
- [ ] `pdf-to-test`: залогиненный пользователь (VIP или нет) — после того как существующая тарифная проверка (формат/лимит страниц) пропустила запрос, добавлены preflight → вызов `callAI` (новая сигнатура) → списание; тарифные 403/400 (`vipRequired`, неверный формат) случаются раньше и не требуют баланса
- [ ] `tests/import-pdf`: TEACHER/ADMIN — preflight → вызов (`callAI`/`callVisionAI`, фото-режим тоже) → списание, поверх существующего `pageLimit`/`isVip`-расчёта; `isAdmin` по-прежнему не платит (см. существующий `privileged`/`isAdmin` в этом файле)
- [ ] Недостаточно средств → HTTP 402, тот же контракт `{error: "INSUFFICIENT_BALANCE", message, neededCents, availableCents}`, что и в тикете 02
- [ ] Ошибка AI-провайдера → баланс не списан
- [ ] Живая проверка через `curl`: гость на `pdf-to-test` с маленьким PDF — как и раньше, без 402/401; залогиненный с нулевым балансом — 402; после пополнения — проходит, баланс списан на сумму, посчитанную из реального usage
- [ ] По возвращении — дописать в `interfaces.md` «Что построено», если что-то уточнилось
