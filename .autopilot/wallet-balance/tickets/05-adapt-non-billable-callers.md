# 05 — Адаптация остальных вызовов callAI/callVisionAI под новую сигнатуру

**Требования:** D01

**Волна:** 2
**Status:** ready

## Что должно заработать

Тикет 01 поменял `callAI`/`callVisionAI` в `src/lib/openrouter.ts`: раньше они возвращали
голую строку, теперь — `{ content: string, usage: AIUsage }`. Это обнаружилось как поломка
сборки: помимо 7 платных AI-эндпоинтов этого брифа (их чинят тикеты 02/03), есть ещё 6 мест
в репозитории, которые зовут те же функции и после этой правки не компилируются.

Ни одно из этих 6 мест не входит в 7 платных эндпоинтов и не должно начать тарифицироваться —
это не про биллинг, а чисто про то, чтобы проект продолжал собираться. Правка — механическая:
заменить `const raw = await callAI(...)` (и `callVisionAI`) на деструктуризацию нового
объекта, оставив имя `raw` для минимального диффа в остальном коде каждого файла
(`const { content: raw } = await callAI(...)`).

## Из спецификации

Раздел «Захват реального usage», строка D01 — находка сборки тикета 01, не новое требование
пользователя.
