# Спецификация — два лендинга файлового хранилища (T1)

## 1. Что строим (R01, R03)
Два автономных статических HTML-файла в `ForNewDesign/prototypes/`:
- `storage-a-preview.html` — «Превью»: слева текст, справа живое превью интерфейса хранилища.
- `storage-b-folders.html` — «Папки»: слева текст, справа большие объёмные папки с файлами.

Это дизайн-разведка (как `wallet-*.html`, `catalog-*.html`): без сборки, без npm, без бэкенда. Правила стека — из `CLAUDE.md` (раздел про прототипы): CSS/JS инлайн, единственная внешняя зависимость — Google Fonts `<link>` с web-safe fallback, вся анимация руками (CSS + vanilla JS), иконки — рисованные inline-SVG (не эмодзи), CTA `href="#"`.

## 2. Мир и копирайт (R02, R10i)
Продукт — «Файловое хранилище» GoodWorker (VIP-репетитор + его ученики). Образец — рекламный hero Google Classroom и приложенный референс: светлый воздушный фон, лавандово-индиго акцент (`--accent:#5b4df0`, мягкие `#eeeaff`/`#f6f4ff`), крупный жирный заголовок с акцентным вторым словом/строкой, плавающие цветные плитки-иконки с мягкой тенью, рукописная подпись со стрелкой. Шрифт — Manrope (fallback system-ui). Радиусы крупные (14–28px), тени мягкие нейтральные.

Копирайт (дословно в обоих файлах, русский):
- Бейдж: «Файловое хранилище»
- H1: «Все учебные материалы — в одном месте» (последние слова «в одном месте» акцентом)
- Подзаголовок: «Хранилище GoodWorker помогает удобно организовать файлы, конспекты и материалы по предметам, ученикам и курсам.»
- CTA основной: «Попробовать бесплатно →»; вторичный: «Как это работает» (плей-иконка, якорь на секцию ниже)
- Рукописная подпись (в обоих): «Удобно и структурно»
- Блок ниже hero (ровно ОДИН, по ответу пользователя «херо +1 блок ниже, оба креативными должны быть»): секция «Всё для учёбы» с 4 тезисами — «Папки по ученикам» — «Личная подпапка у каждого: материалы видны только тому, кому вы их открыли.»; «Доступ на время» — «Откройте папку на нужный срок — и закройте одним кликом.»; «Сдача работ» — «Ученик загружает работу в папку с дедлайном, вы проверяете и возвращаете.»; «Поиск внутри файлов» — «Находите конспект по слову из самого документа, а не только по названию.». НЕ ровная сетка из 4 карточек: креативная подача, своя у каждого дизайна (A — sticky/скролл-связанный показ с мини-сценой на каждый тезис; B — тезисы «разложены» по папкам/ленте файлов, интерактив). Внутри блока — вторая CTA «Попробовать бесплатно →». Отдельной финальной секции нет.
- Мок-данные интерфейса: пользователь-репетитор «GoodWorker», использование «2,4 ГБ из 15 ГБ»; папки: «Конспекты лекций», «Домашние задания», «Материалы», «Курсы»; ученики-аватары: Анна, Илья, Мария, Кирилл (аватар — нарисованное inline-SVG лицо-иллюстрация на цветном круге, НЕ фото и не инициалы (решение пользователя)); файлы: «Линейная алгебра — Конспект.pdf», «Лекция 3 — Аудиозапись.mp3», «Домашнее задание.docx», «Таблица формул.xlsx».
- Никаких выдуманных цен, «бесплатно», счётчиков пользователей.
- Переключатель двух дизайнов — fixed в углу, разметка строго:
```html
<nav data-storage-switcher aria-label="Варианты лендинга хранилища">
  <a data-storage="a" href="storage-a-preview.html">Превью</a>
  <a data-storage="b" href="storage-b-folders.html">Папки</a>
</nav>
```
Активной ставится `aria-current="page"` инлайн-скриптом по имени файла.

## 3. Дизайн A — «Превью» (R05, R06, R07)
Hero: слева текст (§2), справа окно-приложение «Мои файлы» (декстоп-рамка со скруглением, сайдбар папок, шапка с поиском и квотой, сетка карточек папок, список файлов) + опционально небольшой телефон поверх и 2–3 плавающие плитки-иконки.
- **Переключение (R06):** клик по папке в сайдбаре переключает содержимое окна (кросс-фейд + лёгкий слайд списка файлов, индикатор активной папки скользит). Плюс автоплей по кругу (пауза при hover/клике пользователя, возобновление через 6 с).
- **Анимация доступа (R07):** в шапке открытой папки ряд аватаров «Доступ». Цикл: аватар с пружинным «pop» появляется (scale 0→1.1→1 + кольцо-пульс), тост «Анна получила доступ»; у файлов появляется бейдж «открыт»; затем другой аватар сжимается/гаснет и уезжает, тост «Доступ у Ильи закрыт», бейдж файла меняется на замок. Также интерактивно: кнопка «+ Дать доступ» открывает мини-список учеников, клик по ученику добавляет/убирает его аватар с той же анимацией.

## 4. Дизайн B — «Папки» (R08, R09)
Hero: слева текст (§2), справа сцена с 3–4 большими объёмными папками (CSS-объём: задняя стенка, вкладка, передняя створка со скосом, разные цвета: индиго, сиреневый, жёлтый, зелёный; название и счётчик «7 элементов» на створке).
- Файлы — карточки-листы с иконкой типа (pdf/mp3/docx/xlsx), «перелетают» между папками по дуге: лист поднимается, папка-цель приоткрывает створку, лист «влетает» с уменьшением, счётчики обеих папок пересчитываются с «tick»-анимацией, створка закрывается. Автоплей по кругу + реально работающий drag-and-drop мышью/тачем (pointer events) файлов в папки; при отпускании мимо — файл возвращается пружиной.
- Hover на папке: наклон/подъём, створка приоткрывается и «выглядывают» верхушки 2–3 файлов.
- Фоновые плавающие плитки-иконки (облако, документ, замок) с парящим движением, рукописная подпись «Удобно и структурно» со стрелкой.

## 5. Общее по анимациям и адаптиву (R04, R11i)
- Hero-моушен — главный авторский приём каждого файла; плюс reveal секций ниже по скроллу (можно `shared/reveal-core.js` с `[data-reveal]`).
- `prefers-reduced-motion: reduce` — автоплей и парение выключены, контент виден полностью, статичное осмысленное состояние.
- 360–1440px, без горизонтального скролла `body`; на <900px hero в одну колонку (текст сверху, сцена снизу), тяжёлые эффекты упрощены.
- Автоплей ставится на паузу при `document.hidden` и когда hero вне экрана (IntersectionObserver).

## 6. Вне объёма
Реальный продукт, бэкенд, цены, настоящие аватары-фото, i18n.

## 7. Границы
Два файла независимы, общего кода нет (кроме опционального `shared/reveal-core.js`). Публичных сигнатур нет.

## Решения брифинга (interview, 2026-10-06)
- Один бренд, разный hero — оба в лавандово-индиго мире референса.
- Объём: hero + 1 креативный блок ниже.
- CTA «Попробовать бесплатно» — выбор пользователя (утверждение о цене — его).
- Аватары — нарисованные SVG-лица.

## 8. Итерация 2 (2026-10-07) — только `storage-a-preview.html`
Решение пользователя: «оставляем превью (1 вариант)». Дизайн B снят, переключатель вариантов в файле убирается. Дальше правится один файл.
- **Блоки снизу (R12):** под существующим креативным блоком «Всё для учёбы» добавить ещё 4–5 блоков, в том числе текстовых и разных по подаче (не повторять сетку одинаковых карточек): «Как это работает» (3 шага, якорь `#how` уже есть), «Для репетиторов / Для учеников» (две колонки текста), цитата/манифест крупным текстом, FAQ-аккордеон (нативный `<details>`), финальный CTA «Попробовать бесплатно →» + футер. Копирайт — русский, сдержанный, только факты о продукте: личные подпапки, доступ на время и закрытие в клик, сдача работ с дедлайном и проверка, поиск внутри файлов, редактирование .docx, учёт места. Без цен, чисел-обещаний, выдуманных отзывов и счётчиков.
- **Тёмная тема (R13):** все цвета через CSS-токены на `:root`, тёмная палитра в `[data-theme="dark"]`; по умолчанию — `prefers-color-scheme`; кнопка-переключатель (inline-SVG солнце/луна) в углу, выбор в `localStorage` (try/catch), без мигания светлой темы при загрузке (инлайн-скрипт в `<head>`). Тёмная — глубокий индиго-графит, акцент светлее для контраста AA; тени/свечения нейтральные; окно-превью, аватары, плитки, hero и все новые блоки корректны в обеих темах.
