## ASSUMPTIONS (режим semi/full — решено без вопроса пользователю)

- Прототипы живут в `ForNewDesign/prototypes/` как самостоятельные статические HTML (без сборки, без npm), а не как Next.js-компоненты — по прецеденту `catalog-a/b/c-*.html` и `variant-*.html` (design-разведка без реальных данных/платежей укладывается в этот стек; Next.js выбирали только когда нужен был пакет, которого нет — здесь не нужен).
- «3D» в варианте A — глубина через CSS (перспектива/тени/градиенты/параллакс на скролл/курсор), не WebGL.
- Три файла — `wallet-a-3d.html`, `wallet-b-mono.html`, `wallet-c-*.html` (третий вариант получит собственное имя по своей концепции), плюс общий свитчер между ними в стиле `catalog-a/b/c`.
