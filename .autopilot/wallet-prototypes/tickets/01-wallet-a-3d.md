## Что должно заработать

Самостоятельная HTML-страница «Кошелёк», объёмный тёмный дашборд-мир в духе
референс-скриншота из брифа (тёмные карточки Visa/Statistic) — но столбчатая
диаграмма, не круговая. Слева сверху — крупная плашка баланса, стилизованная
под платёжную карту (чип, замаскированный номер, сумма крупно), под ней —
три карточки предложений. Справа — столбчатая диаграмма операций за неделю,
под ней — список последних 5 операций. Всё оживлено: появление блоков по
скроллу, лёгкий 3D-наклон карты баланса на курсор, отрисовка столбцов диаграммы,
hover-отклик на карточках и кнопках. При `prefers-reduced-motion: reduce` —
всё видно сразу, без анимаций. На телефоне (360px) — без горизонтального скролла,
тяжёлые эффекты (наклон на курсор, параллакс, если есть) деградируют на touch.

## Критерии приёмки

- [ ] Баланс 48 200 ₽ — самый крупный текст экрана, левый верхний угол композиции,
      оформлен как платёжная карта (чип-мотив + маскированный номер), без реальных
      логотипов платёжных систем
- [ ] Три карточки предложений (VIP / Pro-план / Личная услуга) сразу под балансом,
      тексты и цена «990 ₽ / месяц» — дословно из `interfaces.md`
- [ ] Справа: столбчатая диаграмма (7 столбцов Пн–Вс, значения из `interfaces.md`,
      суббота — пик), под ней — список из 5 операций с датой/суммой со знаком/статусом
- [ ] Многослойные тени и точечная фоновая текстура — по технике
      `LandingPage.module.scss` (растущий offset/blur теней на hover), акцент —
      `#ED0606` точечно (не заливка блоков)
- [ ] Есть минимум: появление блоков по скроллу (reveal), 3D-наклон карты баланса
      на курсор (`mousemove`, выключен на touch), отрисовка столбцов диаграммы,
      hover-переходы кнопок/карточек — авторские, не одна и та же анимация на всём
- [ ] `nav[data-wallet-switcher]` с тремя ссылками (a/b/c), инлайн-скрипт ставит
      `aria-current="page"` по имени файла; подключён `shared/reveal-core.js` `defer`
- [ ] `@media (prefers-reduced-motion: reduce)` — все анимации/переходы выключены,
      весь контент виден без взаимодействия
- [ ] 360–1440px — нет горизонтального скролла `body`; наклон-на-курсор не активен
      на touch-устройствах
- [ ] Страница открывается в браузере без ошибок в консоли
