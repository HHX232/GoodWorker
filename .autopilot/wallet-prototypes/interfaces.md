# interfaces.md — Кошелёк: 3 дизайн-варианта

## Проектные правила (не выводятся из кода — держать в голове)

- Стек: статический HTML/CSS/JS, инлайн в файле, без сборки/npm/фреймворков/бэкенда.
  Единственная внешняя зависимость — Google Fonts `<link>` в `<head>`, с web-safe
  fallback-стеком. Никаких CDN-скриптов, никаких сторонних JS-библиотек, никакого
  three.js/WebGL. Вся анимация — руками, CSS + vanilla JS.
- Запуск/проверка: открыть файл в браузере (`file://` или `open <файл>.html`).
  Раннера тестов нет — проверка визуальная (см. «Смоук» в каждом тикете).
- Не трогать: `app/`, `src/` (Next.js-приложение), любые другие файлы в
  `ForNewDesign/prototypes/` кроме своего нового файла. Каждый субагент создаёт
  ровно один новый файл и ничего не редактирует за его пределами.
- Недостающая зависимость — не ставим, возвращаем `BLOCKED`. Здесь их не должно
  возникнуть: всё нужное (шрифты, `shared/reveal-core.js`) уже есть в репозитории.
- Копирайт и данные — см. «Данные» ниже, дословно и одинаково во всех трёх файлах.

## Границы, решённые в спецификации

| Что | Владеет | Выставляет (контракт, одинаковый в 3 файлах) | Прячет |
|---|---|---|---|
| Свитчер | каждый файл сам | разметка `nav[data-wallet-switcher]` с `data-wallet="a\|b\|c"`, `aria-current` через инлайн-скрипт по имени файла | стилизацию — своя в каждом мире |
| Мок-данные | каждый файл сам | один и тот же набор чисел/подписей раздела «Данные» ниже, дословно | вёрстку/анимацию карточек — своя в каждом мире |
| Reveal | `ForNewDesign/prototypes/shared/reveal-core.js` (существующий, НЕ трогать) | `[data-reveal]` → класс `.is-in` при въезде в вьюпорт, порог `0.15`, уважает `prefers-reduced-motion` | сам IntersectionObserver |

## Контракт свитчера (вставить дословно в каждый из трёх файлов, стиль — свой)

```html
<nav data-wallet-switcher aria-label="Варианты кошелька">
  <a data-wallet="a" href="wallet-a-3d.html">3D</a>
  <a data-wallet="b" href="wallet-b-mono.html">Ч/Б</a>
  <a data-wallet="c" href="wallet-c-ledger.html">Гроссбух</a>
</nav>
<script>
(function(){
  var file = location.pathname.split('/').pop();
  var links = document.querySelectorAll('nav[data-wallet-switcher] a');
  for (var i = 0; i < links.length; i++) {
    if (links[i].getAttribute('href') === file) links[i].setAttribute('aria-current', 'page');
  }
})();
</script>
```

Nav — fixed, компактный, не перекрывает баланс/CTA. Подключать `shared/reveal-core.js`
(`defer`) рядом с этим скриптом — относительный путь `shared/reveal-core.js` (файл
открывается из `ForNewDesign/prototypes/`, путь работает только оттуда).

## Общий смоук (все тикеты)

- Файл открывается двойным кликом / `open <файл>.html` без ошибок в консоли браузера.
- Три ссылки свитчера ведут на реальные соседние файлы (резолвятся после того, как
  все три тикета собраны — при разработке своего файла остальные два ещё могут не
  существовать, это нормально, ссылки всё равно должны быть корректными по имени).
- Активная ссылка свитчера подсвечена (`aria-current="page"`).
- `prefers-reduced-motion: reduce` → анимации выключены, весь контент виден сразу
  (не завязан на `.is-in`, который иначе не проставится).
- 360–1440px — нет горизонтального скролла `body` (`overflow-x: hidden`).
- Баланс — визуально самый крупный текст на экране, в левом верхнем углу композиции.
- Диаграмма — столбчатая (не круговая/donut).
