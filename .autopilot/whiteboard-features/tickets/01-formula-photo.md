# 01 — «Фото → Формула» на белой доске

**Кому:** агенту, владеющему `src/widgets/VideoRoom/CallWhiteboard/`.
**Зона:** `src/widgets/VideoRoom/CallWhiteboard/FormulaKeyboard.tsx` (или
соседний новый компонент модалки), `app/api/whiteboard/` (новый роут),
`src/lib/openrouter.ts` (только читать — не менять, `callVisionAI` уже готов).
**Blocked by:** ничего, независимо от тикета 02.

## Что должно заработать

Кнопка «Фото → формула» рядом с уже существующей кнопкой AI-ввода формулы
(«текст → LaTeX», `formula-ai` popover в `CallWhiteboard.tsx`). По клику —
модалка:

1. Дропзона/кнопка выбора файла — фото формулы (рукописной или печатной).
2. Превью выбранного фото.
3. Текстовое поле **необязательное** — «Уточните, какую формулу взять» (для
   случая, когда на фото несколько формул или часть решения — учителю нужно
   уточнить словами, что распознавать).
4. Кнопка «Распознать».

По нажатию «Распознать» — фото уходит на бэкенд, распознанная формула
возвращается как **редактируемый LaTeX** в тот же интерфейс, что уже
показывает результат текстового AI-ввода (`FormulaKeyboard`) — пользователь
видит и может поправить текст формулы руками (модели распознавания иногда
путают дроби/индексы/степени), и только потом жмёт «Вставить на доску» —
как уже работает для обычного AI-ввода формулы. Не вставлять на канвас
напрямую, минуя этот шаг проверки.

## Технический контекст (уже есть в проекте — переиспользовать, не изобретать)

- **Vision AI уже подключен**: `callVisionAI(systemPrompt, images, userPrompt, opts)`
  в `src/lib/openrouter.ts` — DeepSeek vision (`DEEPSEEK_VISION_MODEL`),
  принимает `VisionImage[]` (`{mimeType, base64}`), возвращает текст.
  Используется точно по этому же паттерну «фото → структурированный
  результат» в `app/api/pdf-to-test/photos/route.ts` (`handlePhotos`) —
  взять оттуда как образец конвертации `File` → base64 → `callVisionAI` →
  `parseJSON`.
- **Загрузка файла** — если фото нужно сохранить (не обязательно: можно
  прогнать через vision-AI прямо на бэкенде без сохранения в S3, раз
  результат — только текст LaTeX, а не постоянный артефакт) — решить самому,
  но если решите сохранять, использовать существующий `uploadFile()`
  (`src/shared/lib/uploadFile.ts`) → `POST /api/upload` с `folder:
  'whiteboard'`, не создавать новый аплоадер.
- **Сжатие фото перед отправкой** — переиспользовать
  `compressImageForUpload` (`src/shared/helpers/compressImageForUpload.ts`,
  только что построен для чата: canvas → JPEG, отдаёт `File`) вместо новой
  реализации сжатия.
- **LaTeX-редактор уже есть** — `FormulaKeyboard.tsx` (MathLive), уже
  умеет принимать и показывать LaTeX-код от AI (текстовый `formula-ai`
  popover) — новая фича встраивается в тот же путь показа результата, не
  строит новый редактор формул.
- **VIP-гейт** — текстовый AI-ввод формулы (`app/api/whiteboard/formula-ai/route.ts`)
  уже проверяет VIP. Тот же гейт обязателен и здесь — иначе бесплатный тариф
  получает более сильную (фото) версию платной фичи бесплатно.

## Бэкенд

Новый роут `app/api/whiteboard/formula-photo/route.ts` (сосед
`formula-ai/route.ts`, тот же паттерн авторизации/VIP-проверки). Промпт для
`callVisionAI`, примерно:

> «На фото — рукописная или печатная математическая формула.
> {если пользователь дал описание: "Пользователь уточнил: <описание>".}
> Верни ТОЛЬКО LaTeX-код формулы, без пояснений и без обёртки в markdown.
> Если на фото несколько формул и по описанию нельзя однозначно понять,
> какую нужно — верни JSON вида `{"needsClarification": true, "candidates":
> ["<latex1>", "<latex2>", ...]}` вместо голого LaTeX.»

Ответ парсится: если это `{needsClarification: true, ...}` — модалка не
закрывается, показывает кандидатов (или просит явно уточнить описанием) вместо
результата.

## Критерии приёмки

- [ ] Кнопка «Фото → формула» в тулбаре формул, рядом с существующим
      AI-вводом по тексту
- [ ] Модалка: выбор файла, превью, необязательное текстовое уточнение,
      кнопка «Распознать»
- [ ] Реальный вызов `callVisionAI` с фото (проверено на настоящем фото
      формулы — не мок), результат — редактируемый LaTeX в `FormulaKeyboard`,
      а не сразу готовый элемент на канвасе
- [ ] Несколько формул на фото без уточнения → явный запрос уточнения, а не
      случайный выбор одной из них молча
- [ ] VIP-гейт — тот же, что у текстового AI-ввода формулы
- [ ] Фото сжимается на клиенте перед отправкой (`compressImageForUpload`)
- [ ] Тёмная и светлая тема на модалке
- [ ] Все новые пользовательские строки — во всех 4 локалях
      (`messages/{en,hi,ru,zh}.json`), провалидировать `python3 -c "import
      json; json.load(open('messages/<f>.json'))"` на каждый файл
- [ ] Коммит только своих файлов, `git push origin main`
