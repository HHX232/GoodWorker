# 02 — Шаблоны белой доски

**Кому:** агенту, владеющему `src/widgets/VideoRoom/CallWhiteboard/`.
**Зона:** `src/widgets/VideoRoom/CallWhiteboard/` (новая кнопка в тулбаре,
новая модалка `TemplatesModal.tsx` или аналог), `prisma/schema.prisma`
(новая модель), `app/api/whiteboard/templates/` (новые роуты).
**Blocked by:** ничего, независимо от тикета 01.

## Что должно заработать

### Кнопка

Кнопка «Шаблоны» в правой части тулбара доски (там же, где остальные кнопки
инструментов — сетка/3D/формулы). **Текст — по одной букве на строку**, не
повёрнутый на 90°, а именно колонка отдельных букв — чтобы кнопка занимала
минимум места по ширине:

```
Ш
а
б
л
о
н
ы
```

(технически — например, разбить строку на массив символов и вывести каждый в
своём `<span>`/строке с `line-height` близким к 1, `text-align: center`;
НЕ `writing-mode: vertical-rl` — это повернёт сами буквы набок, а нужно
именно поштучное расположение по вертикали, буквы остаются прямыми).

### Модалка шаблонов

По клику на кнопку — модалка с двумя вкладками:
- **«Системные»** (открыта по умолчанию) — список готовых шаблонов «из
  коробки» (см. раздел ниже), только просмотр/выбор, без возможности
  удалить/переименовать.
- **«Мои шаблоны»** — первый элемент списка **всегда** карточка «+ Создать
  шаблон» (не настоящий шаблон, а действие), за ней — шаблоны, которые
  сохранил этот репетитор.

Выбор любого шаблона (системного или своего) из списка — загружает его
на текущий канвас **вместо** текущего содержимого. Если на канвасе уже что-то
есть (не пустой) — подтверждение («Текущее содержимое доски будет заменено —
продолжить?») перед заменой, чтобы не потерять работу случайным кликом.

### Создание шаблона

По клику «+ Создать шаблон»:
1. Маленький инлайн-запрос имени шаблона прямо в модалке («Как назвать
   шаблон?», с осмысленным дефолтом вида «Шаблон от {дата}»).
2. После подтверждения имени — модалка закрывается, в тулбаре доски
   появляется кнопка **«Сохранить шаблон»** (видна, пока пользователь в
   режиме создания шаблона).
3. Пользователь рисует/собирает на канвасе то, что должно быть в шаблоне.
4. Сохранение — либо вручную (клик «Сохранить шаблон» в любой момент — можно
   сохранить и продолжить работать дальше как обычно, кнопка исчезает после
   сохранения), **либо** автоматически в момент закрытия/выхода с доски
   (пользователь так и не нажал «Сохранить» — при закрытии видеозвонка/доски
   сохранить текущее состояние канваса под уже введённым именем, если холст
   не остался абсолютно пустым — не сохранять пустой шаблон молча).

## Из брифа, дословно

> «шаблоны белой доски это хорошо - справа сделать кнопку шаблоны (текст
> вертикально по буквам сделать чтоб в ширину минимум места занимало) - при

> "Создать шаблон" + таб "мои шаблоны". При нажатии создать шаблон появляется
> кнопка "Сохранить шаблон" либо по закрытию доски автоматом сохраняется в

## Какие системные шаблоны сделать

Все восемь опираются только на уже существующие в `CallWhiteboard`
примитивы (фигуры, метки углов/сторон, 3D-зона, сетка) — не требуют новых
типов элементов:

1. **Координатная плоскость** — оси X/Y с делениями, включена сетка —
   под построение графиков функций.
2. **Числовая прямая** — горизонтальная шкала с делениями — неравенства,
   промежутки, младшие классы.
3. **Единичная окружность с углами** — окружность, размеченная 0°/90°/180°/270°
   (и опционально radian-метки) — тригонометрия.
4. **Треугольник с размеченными углами и сторонами** — уже готовый инструмент
   меток углов/сторон, просто предзаполненная фигура — геометрия/подобие.
5. **Пустые оси XYZ в 3D-зоне** — стереометрия, начальная точка вместо
   ручной настройки 3D-сцены с нуля каждый раз.
6. **Таблица N×M (пустая сетка с подписываемыми ячейками)** — организация
   данных, разбор задач по шагам, расписания.
7. **Диаграмма Венna (2 круга)** — множества, логика.
8. **Каркас «Дано / Решение / Ответ»** — три подписанных текстовых блока
   в столбик — самый частый формат разбора задачи у репетиторов, чисто
   текстовый шаблон, самый дешёвый в реализации.

Не включать в первую итерацию (специализированные/тяжёлые в реализации,
можно добавить отдельным тикетом при запросе): периодическая таблица,
схемы электрических цепей, хронологические шкалы — либо требуют нового
типа asset, либо слишком нишевые для универсального набора.

## Технический контекст

- **Формат хранения снапшота** — то же представление канваса, что уже
  использует `CallWhiteboard` внутри (Excalidraw elements + свои
  `customData` для формул/3D-зоны) — сериализовать как есть, не изобретать
  параллельный формат.
- **Системные шаблоны** — не требуют БД: статичный набор снапшотов,
  зашитый в код (например `src/widgets/VideoRoom/CallWhiteboard/templates/system/*.json`
  или аналогичная структура рядом с существующими константами доски).
- **Свои шаблоны репетитора** — нужна персистентность. Предлагается новая
  Prisma-модель:
  ```prisma
  model WhiteboardTemplate {
    id        String   @id @default(uuid())
    teacherId String
    name      String
    snapshot  Json
    createdAt DateTime @default(now())
    teacher   Teacher  @relation(fields: [teacherId], references: [id], onDelete: Cascade)
    @@index([teacherId, createdAt])
  }
  ```
  (обратная связь `Teacher.whiteboardTemplates` — по аналогии с недавно
  добавленными `Teacher.conversationsAsTeacher` и т.п.). Отдельная таблица,
  а не JSON-поле на `Teacher` — шаблонов может быть много, отдельная таблица
  проще листать/удалять поштучно.
- **API**: `GET/POST /api/whiteboard/templates` (список своих + создание),
  `DELETE /api/whiteboard/templates/[id]` (см. критерий ниже про удаление).
  Доступ — только сам репетитор видит и правит свои шаблоны (обычная
  проверка владения по `teacherId` из сессии, как везде в проекте).

## Критерии приёмки

- [ ] Кнопка «Шаблоны» в правой части тулбара, текст — буквы в столбик (не
      повёрнутый текст), минимальная ширина
- [ ] Модалка с двумя вкладками: «Системные» (по умолчанию) и «Мои шаблоны»
- [ ] «Мои шаблоны» — первый элемент всегда «+ Создать шаблон»
- [ ] Восемь системных шаблонов из списка выше, каждый реально загружается на
      канвас и выглядит корректно (проверено визуально, не только код)
- [ ] Клик по шаблону при непустом канвасе — подтверждение перед заменой
- [ ] «Создать шаблон» → запрос имени → появляется кнопка «Сохранить шаблон»
      в тулбаре
- [ ] Ручное сохранение по кнопке работает, кнопка пропадает после сохранения
- [ ] Если пользователь не сохранил вручную и закрыл доску/звонок —
      автосохранение под введённым именем, **кроме случая** когда канвас
      остался пустым (тогда шаблон не создаётся)
- [ ] Сохранённый шаблон реально появляется во вкладке «Мои шаблоны» у этого
      же репетитора при следующем открытии доски — проверено через реальный
      dev-сервер, не только по коду
- [ ] Возможность удалить свой шаблон (иконка корзины при наведении в списке
      «Мои шаблоны») — минимальный CRUD, переименование можно не делать в
      этой итерации
- [ ] Тёмная и светлая тема на кнопке и модалке
- [ ] Все новые пользовательские строки — во всех 4 локалях, провалидировать
      `python3 -c "import json; json.load(open('messages/<f>.json'))"`
- [ ] Миграция создана и применена (`set -a; source .env; set +a` →
      `npx prisma migrate deploy`, затем `npx prisma generate`)
- [ ] Коммит только своих файлов, `git push origin main`
