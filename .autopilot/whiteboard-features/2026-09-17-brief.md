# Бриф — доработки белой доски (формулы + шаблоны)

Источник: постановка пользователя в диалоге с «третьим агентом» (не владельцем
`CallWhiteboard/`), 2026-09-17. Записано дословно, без интерпретации.

## Сообщение 1 — про формулы (исходный запрос)

> предложи идеи для белой доски, что для кого добавить
>
> Подумай как улучшить работу с формулами – как миниум надо добавить "Фото в
> Формулу" на доске - дипсик читает формулу с фото, при том это должно
> вызывать модалку где прикрепляется файл + описание дополнительное к фото
> чтоб было понятнее какую формулу из на фото брать, описание необязательно

## Сообщение 2 — про шаблоны (после того как агент предложил идею шаблонов)

> шаблоны белой доски это хорошо - справа сделать кнопку шаблоны (текст
> вертикально по буквам сделать чтоб в ширину минимум места занимало) - при
> нажатии открывается модалка со списком шаблонов и первый щаблон всегда
> "Создать шаблон" + таб "мои шаблоны". При нажатии создать шаблон появляется
> кнопка "Сохранить шаблон" либо по закрытию доски автоматом сохраняется в
> таком случае.
>
> Какие системные шаблоны сделать?
>
> Оформи тикеты для агентов по формуле и описанному выше
