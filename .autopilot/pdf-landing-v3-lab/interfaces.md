# interfaces.md — контракты (итерация 2, V3-лаборатория)

Единый источник правды. Читается ДО кода. **Всё в одном файле `v3-lab.html`** →
тикеты идут последовательно, каждый ДОПИСЫВАЕТ, сохраняя сделанное раньше (панель,
токены, ранее собранные hero/секции не ломать).

## Правила проекта

- Стек: статические HTML/CSS/JS, инлайн, без сборки/npm/фреймворков/бэкенда. Можно
  подключить общий `shared/reveal-core.js`. Единственная внешняя зависимость — Google
  Fonts через `<link>` с fallback. Нет CDN-JS, нет библиотек. Анимации — руками.
- Файл: `ForNewDesign/prototypes/v3-lab.html`. Писать только в него (+ при нужде
  правка карточки V3 в `ForNewDesign/prototypes/index.html`). НЕ трогать `app/`, `src/`,
  `variant-a/b/c-*.html`, `.autopilot/`. `variant-c-cinematic.html` — **база-референс мира V3**
  (палитра, шрифты, секции, нынешний морф-hero, копирайт) — читать, не менять.
- Недостача → `BLOCKED`, ничего не ставить.
- Верификация (смоук): открывается без ошибок консоли; панель двигает токены/гамму/hero/
  шаги; localStorage сохраняет/восстанавливает; экспорт кладёт корректный CSS (или fallback);
  `prefers-reduced-motion` гасит движение (hero — финальный кадр); адаптив 360–1440 без
  горизонтального скролла body.
- Язык — русский; копирайт V3 берётся из `variant-c-cinematic.html` дословно, дельты — ниже.

## Контракт токенов (все секции используют переменные, НЕ хардкод)

На `:root`:
```
/* типографика — управляются ползунками панели */
--fs-hero      дисплей hero (дефолт ЗАМЕТНО меньше нынешнего V3)
--fs-h2        заголовки секций
--fs-lead      ведущий абзац
--fs-body      основной текст
--tracking-display  межбуквенное дисплея (em)
--leading      интерлиньяж текста (unitless)
--section-rhythm    вертикальный ритм между секциями (px/rem)
/* акцент — управляется селектором гамм */
--accent, --accent-soft, --accent-ink
/* тёмная чертёжная подложка blueprint-hero */
--draft-bg  ≈ #12140f
```

## Контракт панели и селекторов (задаёт тикет 01)

- Корень `<html>` (или `<body>`) несёт `data-active-hero="1|2|3|4"` и `data-active-steps="1|2|3"`.
- Каждая hero — `<section data-hero="N">`; CSS показывает только активную (`[data-active-hero="N"] [data-hero="N"]{display:...}`, прочие `display:none`). Scroll-логика работает только у активной.
- Вариации шагов — `<section data-steps="N">`, аналогично.
- Панель (фиксированная, сворачиваемая; на мобильном — кнопка-тумблер) секции:
  `Типографика` (ползунки → пишут в `--fs-*`,`--tracking-display`,`--leading`,`--section-rhythm`),
  `Гамма` (свотчи → ставят `--accent*`), `Hero` (4 кнопки → `data-active-hero`),
  `Три шага` (3 кнопки → `data-active-steps`), `Экспорт`/`Сбросить`.
- Persistence: `localStorage['pdfland:v3lab']` = JSON `{ fs:{hero,h2,lead,body}, tracking, leading, rhythm, gamut:"<id>", hero:N, steps:N }`; восстановление на загрузке (try/catch — при недоступном localStorage панель всё равно работает).
- Экспорт: кнопка собирает `:root{ … текущие токены … }` + строку «hero N · steps N · гамма <id>» и кладёт в буфер (`navigator.clipboard.writeText`, fallback — показать `<textarea>`/prompt с текстом, т.к. на file:// clipboard может быть закрыт).

## Hero-анимации (4; scroll-driven; reduced-motion → статичный финал)

- **H1 — Blueprint Exploded (изометрия), тёмная подложка.** 2D-SVG изометрический разрез
  PDF→тест: слои (страницы PDF → распознанные вопросы → модули типов → собранный тест)
  разъезжаются/съезжаются по прогрессу скролла; тонкие линии, акцентные выноски-подписи
  («6 типов», «N вопросов», «OCR», «автопроверка»), нумерация. Внизу — **список состава**
  (`01 Страницы PDF`, `02 Распознанные вопросы`, `03 Типы ответов`, `04 Собранный тест` +
  значение справа), привязан к скроллу («перемотка прокруткой»): активный слой подсвечивается.
- **H2 — Blueprint Exploded, другая композиция, тёмная подложка.** Иной ракурс (напр.
  фронтальный «разлёт» стопки-документа) — реальный вариант, не копия H1.
- **H3 — Вопросы из бланка → в блок ниже.** Из бланка по скроллу отделяются карточки-вопросы
  и «перелетают» вниз, встраиваясь в секцию вопросов вместе с остальными.
- **H4 — Уточнённый V3-морф.** Нынешний sticky-морф V3, но бланк детальнее: «фото» на бланке
  (авторский Ч/Б-плейсхолдер или встроенный data-URI, без внешнего стока), строки текста,
  аккуратное выделение распознанного, выноски-пояснения.

Дефолтный hero тикета 01 — **H4-база** (перенести нынешний морф V3 как есть), детализацию
бланка H4 и heroes H1/H2/H3 добавляют следующие тикеты.

## Вариации «Три шага» (3; та же тройка Загрузка→Распознавание→Готовый тест)

## Копирайт-дельты (РУ, дословно)

- Секция «Честно про лимиты» → заголовок **«Лимиты»**. Три уровня:
  - `Гость` — `5 вопросов с одной страницы · только PDF`
  - `Авторизованный` — `до 20 вопросов · PDF + DOCX, TXT, RTF, ODT`
  - `VIP` — `Без лимита на вопросы · все форматы` + кнопка `Купить VIP`
  - Цена — заглушка `[ЦЕНА VIP — впиши]`; кнопки `href="#"` (placeholder).
- Панель: `Типографика` · `Гамма` · `Hero` · `Три шага` · `Экспорт` · `Сбросить`.
- Остальной копирайт V3 — без изменений (из variant-c-cinematic.html).

## Крафт-правила (планка R13 — craft-floor + бриф)

- Наследовать мир V3; акцент — гаммой, точечно (линии/выноски/CTA/актив), НЕ заливать блоки.
- Blueprint-hero — тёмная подложка + тонкие акцентные линии (референс).
- Дефолтные размеры шрифтов заметно меньше нынешнего V3 (жалоба «текст перебор»).
- Один авторский моушен-момент на hero; reveal на секциях (ядро `reveal-core.js`).
- `prefers-reduced-motion` везде; иконки — SVG (не эмодзи); адаптив 360–1440.
- Запрещённое craft-floor: градиентный текст, стекло-декор, eyebrow, бессмысленные номера,
  цветной border >1px, системный дисплей-шрифт, одинаковые карточки как структура.
