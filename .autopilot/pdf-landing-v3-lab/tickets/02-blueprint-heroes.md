## Что должно заработать

В каркас hero из тикета 01 добавляются два blueprint-hero на **тёмной чертёжной подложке**
(референс пользователя: тёмный фон, тонкие акцентные линии, выноски с пояснениями). 2D-SVG
изометрия, которая по прогрессу скролла **разбирается из цельного в разобранное и обратно**.

- **H1** (`data-hero="1"`): изометрический разрез процесса PDF→тест — слои (страницы PDF →
  распознанные вопросы → модули типов ответов → собранный тест) разъезжаются/съезжаются по
  скроллу; акцентные выноски-подписи («6 типов», «N вопросов», «OCR», «автопроверка»),
  нумерация. Внизу — список состава (`01 Страницы PDF` … `04 Собранный тест` + значение),
  привязанный к скроллу («перемотка прокруткой»): активный слой подсвечивается.
- **H2** (`data-hero="2"`): тот же приём, но другая композиция/ракурс (напр. фронтальный
  «разлёт» стопки) — реальный вариант, не копия H1.

## Из брифа, дословно

> «я люблю такие чертежи 3д (скрин) но при этом они 2д svg которые из цельного разбираются в разобранный и наоборот. Сделай 2-3 hero секции где будет такая анимация»

## Разделы спецификации / interfaces.md

Решения (H1, H2, тёмная подложка); interfaces.md — Hero-анимации H1/H2, `--draft-bg`,
на тёмном красить линии `--accent-soft`. Токены/каркас/панель тикета 01 — НЕ ломать.

## Критерии приёмки

- [ ] H1 и H2 подключены как `<section data-hero="1">`/`="2">`, выбираются кнопками панели, показывается только активный.
- [ ] Оба — 2D-SVG на тёмной подложке `--draft-bg`; линии/выноски — `--accent-soft` активной гаммы (контраст на тёмном); смена гаммы перекрашивает.
- [ ] Анимация scroll-driven: цельное ↔ разобранное по прогрессу скролла (разбирается и собирается).
- [ ] H1: список состава внизу привязан к скроллу, активный слой подсвечивается; выноски с подписями читаются, не перекрываются.
- [ ] H2 — заметно иная композиция, чем H1.
- [ ] Размеры/типографика — через токены тикета 01 (панель их двигает и на этих hero).
- [ ] `prefers-reduced-motion` → статичный финальный (собранный) кадр, контент виден; адаптив 360–1440 без горизонтального скролла.
- [ ] H4-база и S1, панель, прочие секции — сохранены, не сломаны.
- [ ] Верни контракт-блок.
