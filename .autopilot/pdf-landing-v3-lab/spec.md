# Спецификация: V3-лендинг + дизайн-лаборатория (итерация 2)

## Задача

Из трёх прототипов выбран мир **V3 (Cinematic)**. Но текст в нём крупноват, хочется
живьём подобрать размеры и акцентный цвет, попробовать разные hero-анимации и разные
подачи «Три шага», а секцию лимитов довести до продаж VIP. Нужен один V3-лендинг со
встроенной **панелью-лабораторией**, где всё это переключается вживую и сохраняется.

## Решение

Один самодостаточный файл `ForNewDesign/prototypes/v3-lab.html` — эволюция мира V3 —
с фиксированной **панелью управления** (дизайн-лаборатория): ползунки размеров шрифтов,
выбор акцентной цветовой гаммы (≥4), выбор одной из **4 hero-анимаций**, выбор одной из
**3 вариаций «Три шага»**; настройки сохраняются (localStorage) и экспортируются кнопкой
(«скопировать CSS/значения»). Секция «Честно про лимиты» → «Лимиты» с явным VIP-без-лимита
и кнопками покупки VIP (цена/оплата — заглушки). Прежние V1/V2 не трогаем (архив);
`index.html` ведёт V3 на новый `v3-lab.html`.

## Решения по реализации

- **Файл.** Один self-contained `ForNewDesign/prototypes/v3-lab.html` (инлайн CSS/JS,
  без сборки/фреймворков). Может подключать общий `shared/reveal-core.js`. Прежний
  `variant-c-cinematic.html` остаётся как архивная база (не трогать). *Почему:* всё
  переключается вживую в одном месте — это дизайн-лаборатория, не набор страниц.
- **Токены типографики.** Ключевые размеры — CSS-переменные на `:root`: `--fs-hero`
  (дисплей), `--fs-h2` (заголовки секций), `--fs-lead`, `--fs-body`. Все секции
  используют их, не хардкод. Ползунки панели пишут в эти переменные (px). Дефолты —
  ЗАМЕТНО меньше нынешнего V3 (чинит «текст перебор»). «И тому подобное» (бриф) —
  сверх размеров ещё ползунки: `--tracking-display` (межбуквенное дисплея),
  `--leading` (интерлиньяж текста), `--section-rhythm` (вертикальный ритм секций).
  *Почему:* R02/R02.1 — «ползунки размеров шрифтов и тому подобное».
- **Гаммы (акцент).** CSS-переменные `--accent`, `--accent-soft`, `--accent-ink`.
  Основные секции — Ч/Б (тёплая бумага V3); гамма красит только акценты — тонкие линии,
  выноски, активные состояния, CTA — не заливает блоки. ≥4 именованные гаммы:
  бархатный бордовый, книжно-жёлтый, чернильно-бирюзовый, лесной зелёный (плюс,
  опц., терракота). Селектор — свотчи. *Почему:* R08/R08.1 + сохранить Ч/Б-дух.
- **Тёмная «чертёжная» поверхность у blueprint-hero.** Референс пользователя — тёмный
  фон + акцентные линии. Поэтому blueprint-hero (H1/H2) рендерятся на **тёмной**
  подложке (`--draft-bg` ≈ `#12140f`), где тонкие линии и выноски окрашены активной
  гаммой (`--accent`), как на референсе. Это драматичный тёмный hero внутри светлой
  V3-страницы (киношный контраст), остальные секции — светлые. *Почему:* НЕ ПОКРЫТО —
  тёмный фон референса.
- **Селекторы hero и шагов.** Каждая hero — `<section data-hero="1..4">`, панель ставит
  `data-active-hero` на корне, CSS показывает только активную; scroll-логика работает
  только у активной. Аналогично `data-steps="1..3"` + `data-active-steps`. *Почему:*
  live-переключение без перезагрузки (R03, R09).
- **Панель (дизайн-лаборатория).** Фиксированная, сворачиваемая; на мобильном —
  кнопка-тумблер. Секции: Типографика (ползунки), Гамма (свотчи), Hero (4 кнопки),
  «Три шага» (3 кнопки), Экспорт. Настройки → `localStorage['pdfland:v3lab']` (JSON),
  восстановление на загрузке (try/catch). Экспорт: собирает `:root{ --fs-*; --accent* }`
  + выбранные hero/шаги/гамму, кладёт в буфер (`navigator.clipboard`, fallback —
  показать текст для ручного копирования, т.к. на file:// clipboard может быть закрыт).
  *Почему:* R15 + R15.1/R15.2, надёжность на file://.
- **Hero-анимации (4).** Все scroll-driven, reduced-motion → статичный финал:
  - **H1 — Blueprint Exploded (изометрия).** 2D-SVG изометрический «разрез» процесса
    PDF→тест на тёмной чертёжной подложке: слои (страницы PDF → распознанные вопросы →
    модули типов ответов → собранный тест) разъезжаются/съезжаются по прогрессу скролла;
    тонкие линии, выноски-пояснения в стиле референса (акцентные лидеры, подписи «6 типов»,
    «N вопросов», «OCR», «автопроверка»), нумерованные элементы. Внизу — **список состава**
    процесса (по строке на слой: `01 Страницы PDF`, `02 Распознанные вопросы`,
    `03 Типы ответов`, `04 Собранный тест`, справа — значение вроде счётчика), и он привязан
    к скроллу («перемотка прокруткой» из референса): активный слой подсвечивается по мере
    разбора/сборки диаграммы.
  - **H2 — Blueprint Exploded, другая композиция.** Тоже на тёмной подложке, но иной
    ракурс/раскладка того же приёма (напр. фронтальный «разлёт» стопки-документа),
    чтобы это был реальный вариант, а не копия H1.
  - **H3 — Вопросы из бланка → в блок ниже.** Из бланка по скроллу отделяются
    карточки-вопросы и «перелетают» вниз, встраиваясь в секцию вопросов вместе с
    остальными (hero физически питает секцию «готовый тест»).
  - **H4 — Уточнённый V3-морф.** Нынешний sticky-морф V3, но бланк детальнее: «фото»
    на бланке (авторский Ч/Б-плейсхолдер/встроенный data-URI, без внешнего стока),
    строки текста, аккуратное выделение распознанного, выноски-пояснения.
- **Лимиты + VIP.** Заголовок «Лимиты». Три уровня: Гость — 5 вопросов (лимит),
  Авторизованный — 20 вопросов (лимит), **VIP — без лимита** (+ форматы DOCX/… как в
  PRODUCT.md). Кнопки «Купить VIP» с ценой-заглушкой `[ЦЕНА VIP — впиши]`, `href="#"`.
  *Почему:* R10/R11/R12; цену не выдумываем (R17).
- **index.html.** Карточка V3 ведёт на `v3-lab.html` (или добавить карточку «V3 Lab»).
  V1/V2 без изменений.
- **Верификация.** Смоук: открывается без ошибок; панель двигает токены/гамму/hero/шаги;
  localStorage сохраняет; экспорт кладёт корректный CSS (или показывает fallback);
  reduced-motion гасит движение; адаптив 360–1440 без горизонтального скролла.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| панель-лаборатория | UI управления + токены + persistence + export | контракт токенов `--fs-*`/`--accent*`; корневые `data-active-hero`/`data-active-steps`; ключ `localStorage['pdfland:v3lab']` | реализацию ползунков/свотчей/сериализации |
| hero-фреймворк | набор `<section data-hero>` | каждая hero использует токены; scroll-логика только у активной | внутренности каждой анимации |
| steps-фреймворк | `<section data-steps>` ×3 | используют токены | вёрстку каждой вариации |
| `v3-lab.html` | весь файл (инлайн) | сам файл | всё вышеперечисленное |

**Один файл → тикеты по нему сериализуются** (общая зона), параллелизма нет. Контракт
токенов и `data-*` селекторов задаётся тикетом-фундаментом и копируется в `interfaces.md`
дословно — heroes/steps плагинятся в него, а не изобретают свой.

## Контент (изменения к V3, копирайт РУ)

- Секция «Честно про лимиты» → **«Лимиты»**. Три колонки/уровня:
  - `Гость` — `5 вопросов с одной страницы · только PDF` (лимит)
  - `Авторизованный` — `до 20 вопросов · PDF + DOCX, TXT, RTF, ODT` (лимит)
  - `VIP` — `Без лимита на вопросы · все форматы` + кнопка `Купить VIP` (`[ЦЕНА VIP]`)
- Панель: подписи — `Типографика`, `Гамма`, `Hero`, `Три шага`, `Экспорт`, `Сбросить`.
- Гаммы (названия): `Бордовый`, `Книжно-жёлтый`, `Бирюзовый`, `Лесной` (+ опц. `Терракота`).
- Остальной копирайт V3 (hero-заголовок, шаги, типы, профиль ошибок, FAQ, финал) — без изменений.
