# Тикет 03 — Блок «Синтаксис»

Реализует R01, R02, R04, R06, R08, R09, R10 для блока «Синтаксис». Контракты —
`interfaces.md`. Новый файл `prisma/seedRussianCourse03Syntax.ts`, идемпотентный.
Независим от тикетов 01/02/04 — не трогать их файлы.

## Категория-родитель

`syntax` (уже в БД).

## Листовые темы (10: 2 уже в БД + 8 новых)

1. `simple-sentence` (уже в БД) — **Простое предложение** — главные и
   второстепенные члены. Объяснение: разбор предложения по членам с опорной схемой.
   Проверка: `HIGHLIGHT_TEXT` (выделить подлежащее/сказуемое).
2. `complex-sentence` (уже в БД, уточнить название при правке БД под
   **«Сложноподчинённое предложение: виды придаточных»**, если текущее название в
   БД шире — сузить смысл слага правкой перевода, не менять сам slug) — виды
   придаточных по вопросу и союзному слову. Объяснение: таблица «вопрос →
   тип придаточного». Проверка: `CHOOSE_OPTION`.
3. `phrase-connection` (новая) — **Словосочетание: виды связи** — согласование,
   управление, примыкание. Объяснение: как определить тип связи по главному слову.
   Проверка: `MATCH_PAIRS`.
4. `one-part-sentence` (новая) — **Односоставные предложения** — назывные,
   определённо-личные, неопределённо-личные, безличные, обобщённо-личные.
   Объяснение: 5 типов с примерами и опорным признаком каждого. Проверка:
   `CHOOSE_OPTION`.
5. `homogeneous-parts` (новая) — **Однородные члены предложения** — союзы при
   однородных, обобщающие слова. Объяснение: правило + частые ошибки (пропуск
   запятой перед «а»/«но»). Проверка: `FILL_TEXT`/`HIGHLIGHT_TEXT`.
6. `isolated-members` (новая) — **Обособленные определения и обстоятельства** —
   причастный и деепричастный обороты, условия обособления. Объяснение: схема
   «до/после определяемого слова». Проверка: `HIGHLIGHT_TEXT`.
7. `introductory-words` (новая) — **Вводные слова, конструкции и обращения** —
   отличие вводного слова от члена предложения (например vs например —
   омонимичные случаи). Объяснение: список частых вводных + приём проверки
   («можно убрать без потери смысла — вводное»). Проверка: `CHOOSE_OPTION`.
8. `compound-sentence` (новая) — **Сложносочинённое предложение** — союзы и
   смысловые отношения между частями. Объяснение: таблица союзов по значению.
   Проверка: `MATCH_PAIRS`.
9. `asyndetic-sentence` (новая) — **Бессоюзное сложное предложение** — смысловое
   отношение между частями → знак препинания (запятая/точка с запятой/двоеточие/
   тире). Объяснение: алгоритм выбора знака по смыслу. Проверка: `FILL_TEXT`.
10. `direct-speech` (новая) — **Прямая речь, косвенная речь, цитирование** —
    перевод прямой речи в косвенную, оформление цитат. Объяснение: схемы пунктуации
    для позиции слов автора. Проверка: `FILL_TEXT`.
