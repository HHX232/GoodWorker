# Тикет 01 — Блок «Орфография»

Реализует R01, R02, R04, R06, R08, R09, R10 (`manifest.md`) для блока «Орфография».
Контракты — `interfaces.md` (читать целиком до первой строчки кода). Не трогать
`prisma/seed.ts` напрямую — новый файл `prisma/seedRussianCourse01Orthography.ts`,
идемпотентный (upsert по slug/уникальным полям, повторный запуск не плодит дубли).

## Категория-родитель

`orthography` (уже есть в БД, id искать по slug, не хардкодить).

## Листовые темы (8: 2 уже в БД + 6 новых)

Формат: `slug` — **название (ru)** — описание — идея объяснения — идея проверки.

1. `spelling-words` (уже в БД) — **Правописание слов** — общий свод трудных
   написаний вне единого правила. Объяснение: словарь-минимум 40 слов с пометкой,
   почему именно так. Проверка: короткий тест `FILL_TEXT`/`CHOOSE_OPTION`, большой —
   `FILL_TEXT` на объёмном тексте.
2. `prefixes-suffixes` (уже в БД) — **Приставки и суффиксы** — приставки на З/С,
   ПРЕ-/ПРИ-. Объяснение: смысловое различие пре-/при- с примерами-минимальными
   парами. Проверка: `CHOOSE_OPTION`.
3. `unstressed-vowels-root` (новая) — **Безударные гласные в корне** — проверяемые
   (подбор однокоренного), непроверяемые (словарные), чередующиеся (по условию —
   ударение/суффикс/значение). Объяснение: три типа отдельными разделами с
   примерами-ловушками. Проверка: `FILL_TEXT` (вставить букву в 10 словах).
4. `hard-soft-signs` (новая) — **Ъ и Ь: разделительные и обозначающие мягкость** —
   правило + список исключений. Объяснение: схема «после приставки на согласный
   перед Е/Ё/Ю/Я/И → Ъ». Проверка: `FILL_TEXT`.
5. `ne-ni-spelling` (новая) — **НЕ и НИ с разными частями речи** — слитно/раздельно
   по части речи и контексту (отрицание/усиление). Объяснение: дерево решений по
   частям речи. Проверка: `CHOOSE_OPTION`.
6. `n-nn-spelling` (новая) — **Н и НН в разных частях речи** — причастия vs
   отглагольные прилагательные, суффиксы -ённ-/- енн- vs -ан-/-ян-/-ин-. Объяснение:
   главный алгоритм-ловушка ОГЭ/ЕГЭ пошагово. Проверка: `FILL_TEXT` на 10 словах.
7. `hyphenation-rules` (новая) — **Слитное, дефисное и раздельное написание** —
   сложные слова, наречия, служебные слова. Объяснение: таблица по частям речи с
   примерами. Проверка: `CHOOSE_OPTION`.
8. `endings-spelling` (новая) — **Правописание падежных и личных окончаний** —
   склонение существительных/прилагательных, спряжение глаголов. Объяснение: сводные
   таблицы окончаний. Проверка: `FILL_TEXT`.

## На каждую тему

1–2 поста, 2 теста (короткий + большой), 1 PDF-шпаргалка, 1 обложка через kie.ai —
контракты форм и API в `interfaces.md` §3–§7. Один из постов темы прикрепляет оба
теста (`TEST_LINK`) и шпаргалку (`FILE_LIST`).

## Плюс

тем с одной строкой правила на тему.
